\section{Foundations}
% ============================================================================

A \textbf{graph} $G = (V, E)$ models objects (\textbf{vertices} $V$) connected by pairwise links (\textbf{edges} $E$). Roads between cities, friendships in a social network, software build prerequisites, and neighboring open cells in a 2D maze are all graphs in disguise.

\begin{notationbox}[Symbols Used in Graph Foundations]
$G = (V, E)$ & Graph with vertex set $V$ and edge set $E$ & $|V| = 4,\; |E| = 5$ \\
$\deg(v)$ & Degree of vertex $v$ in an undirected graph (incident edge count) & $\deg(2) = 3$ \\
$\deg^-(v),\; \deg^+(v)$ & In-degree (incoming edges) and out-degree (outgoing edges) in a digraph & $\deg^-(0) = 0$ \\
$u \to v,\; w(u, v)$ & Directed edge from $u$ to $v$ with numerical weight $w$ & $(0 \to 1,\; w = 5)$ \\
\end{notationbox}

\subsection{Core Classifications and the Handshaking Lemma}

Four binary questions classify almost every graph you will meet:

\begin{enumerate}
    \item \textbf{Directed vs.\ Undirected:} Undirected edges $(u, v)$ work both ways; directed edges $u \to v$ are one-way arrows.
    \item \textbf{Weighted vs.\ Unweighted:} Unweighted edges all cost $1$; weighted edges carry arbitrary costs, distances, or latencies.
    \item \textbf{Cyclic vs.\ Acyclic:} A \textbf{cycle} starts and ends at the same vertex along a positive-length path. A directed graph with zero cycles is a \textbf{Directed Acyclic Graph (DAG)}.
    \item \textbf{Trees as Special Graphs:} A \textbf{tree} is a connected, undirected, acyclic graph. Every tree on $|V|$ vertices has \textbf{exact} edge count $|E| = |V| - 1$: adding any edge forms a cycle, and deleting any edge disconnects it.
\end{enumerate}

\begin{formulabox}[Handshaking Lemma in Plain English]
$$\sum_{v \in V} \deg(v) = 2|E|$$
\textbf{Read this as:} Because every undirected edge has two endpoints, adding up every vertex's neighbor count counts each edge exactly twice. That is why iterating over every neighbor list in an adjacency list takes $O(V + E)$ total time, not $O(V \cdot E)$!
\end{formulabox}

\examplebeat On a 4-node undirected graph with edges $(0,1), (0,2), (1,2), (2,3)$ ($|E| = 4$), degrees are $\deg(0) = 2,\; \deg(1) = 2,\; \deg(2) = 3,\; \deg(3) = 1$, summing to $2 + 2 + 3 + 1 = 8 = 2 \times 4$.

\subsection{Graph Representations in Code}

\painbeat Storing a $10^5$-node road network in a 2D matrix allocates $10^{10}$ integers ($\approx 40\text{ GB}$ RAM) and crashes immediately---even though each intersection connects to only $3$ or $4$ streets!

\ahabeat Match the storage layout to how your algorithm reads edges:
\begin{enumerate}
    \item \textbf{Adjacency List ($O(V + E)$ space):} Vector of neighbor vectors (\texttt{std::vector<std::vector<int>> adj(V)}). Scanning neighbors of $u$ takes $O(\deg(u))$ time. \textbf{Default choice for sparse graphs.}
    \item \textbf{Adjacency Matrix ($O(V^2)$ space):} 2D grid where \texttt{mat[u][v]} stores weight or $\infty$. Gives $O(1)$ edge lookup; use only when $|V| \le 500$ (e.g., Floyd-Warshall).
    \item \textbf{Edge List ($O(E)$ space):} Flat vector of structs \texttt{\{u, v, weight\}}. Ideal for sorting all edges in Kruskal's MST or sweeping all edges in Bellman-Ford.
\end{enumerate}

\subsection{Breadth-First Search (BFS)}

\painbeat Exploring a maze depth-first might wander through $100$ corridors before stumbling onto an exit that was only $2$ steps from the entrance!

\ahabeat \textbf{Breadth-First Search (BFS)} expands outward in concentric distance ripples using a \textbf{FIFO queue} (\texttt{std::queue<int>}). Every vertex at distance $d$ is popped and expanded before \emph{any} vertex at distance $d + 1$, so the very first arrival at any node $v$ is guaranteed to use the fewest edges (Figure~\ref{fig:graph-bfs-wave}).

\invariantbeat{BFS FIFO Monotonicity} At every instant, the queue holds only vertices at distance $d$ followed by vertices at distance $d + 1$.

\subsection{Depth-First Search (DFS) and Cycle Detection}

\textbf{Depth-First Search (DFS)} plunges down one branch until hitting a dead end, then backtracks via the recursion call stack (or an explicit \texttt{std::stack<int>}).

\textbf{Undirected Cycle Detection:} Since undirected edges are two-way, immediately seeing the parent you just walked from is \emph{not} a cycle. An undirected graph has a cycle if and only if DFS sees a visited neighbor $v \neq \text{parent}(u)$. On triangle $A - B - C - A$, walking $A \to B \to C$ skips parent $B$ and flags visited non-parent $A$.

\painbeat Why does simple boolean \texttt{visited} (with parent tracking) \textbf{break on directed graphs}? In a diamond DAG ($0 \to 1 \to 3$ and $0 \to 2 \to 3$), DFS reaches $3$ via $0 \to 1 \to 3$, finishes $3$, backtracks, and later reaches $3$ again via $0 \to 2 \to 3$. A 2-state \texttt{visited} check falsely screams ``cycle''!

\ahabeat Split ``visited'' into two distinct states---\textbf{Three-Color DFS}:
\begin{itemize}
    \item \textbf{White (0 --- Unvisited):} Never seen yet.
    \item \textbf{Gray (1 --- Active on Call Stack):} Currently exploring its descendants.
    \item \textbf{Black (2 --- Finished):} Completely explored and unwound off the stack.
\end{itemize}
A directed graph contains a cycle \textbf{if and only if} DFS traverses an edge into a \textbf{Gray} ancestor (a \emph{back-edge}). Entering a \textbf{Black} node merely joins an already-finished branch (Figure~\ref{fig:graph-dfs-3color}).

\subsection{Connected Components and Implicit Grid Graphs (Flood Fill)}

Many problems give an $R \times C$ matrix where each cell $(r, c)$ is an implicit vertex linked to its four cardinal neighbors. Rather than writing four copy-pasted \texttt{if} blocks, iterate over direction offsets:
\begin{itemize}

\end{itemize}

\subsection{Topological Sorting (DAGs) and Kahn's Algorithm}

\painbeat In a build system where module $u$ must compile before module $v$ ($u \to v$), running modules in arbitrary numeric order crashes whenever a prerequisite is missing---and circular dependencies deadlock forever!

\ahabeat Any node with \textbf{in-degree} $\deg^-(v) = 0$ has zero remaining prerequisites and can safely run next. \textbf{Kahn's Algorithm} pushes all $\deg^- = 0$ nodes into a queue, pops them into the output order, and decrements each neighbor's $\deg^-$. Whenever a neighbor drops to $0$, it joins the queue!

\begin{calloutbox}{Why Kahn's Algorithm Detects Cycles Automatically}
No vertex belonging to a directed cycle can ever have all of its incoming edges removed, so its $\deg^-$ never reaches $0$. Therefore, when the queue empties, $|\text{order}| < |V|$ \textbf{if and only if} the graph contains at least one cycle!
\end{calloutbox}

\subsection{Dijkstra's Algorithm (Non-Negative Weighted Shortest Paths)}

\begin{notationbox}[Symbols Used in Shortest-Path Algorithms]
$w(u, v)$ & Weight (cost/latency) of directed edge $u \to v$ & $w(2, 1) = 1$ \\
$d[u]$ & Best known tentative distance from source $s$ to vertex $u$ & \texttt{std::int64\_t} \\
$\infty$ (\texttt{INF}) & Overflow-safe unreachable distance sentinel & \texttt{INT64\_MAX / 2} \\
\end{notationbox}

\painbeat When roads have different travel times, a 2-hop highway ($1 + 1 = 2$ min) beats a 1-hop traffic jam ($10$ min). Unweighted BFS minimizes edge count, not total weight!

\ahabeat \textbf{Dijkstra's Algorithm} greedily expands the unsettled vertex $u$ with the \textbf{smallest tentative distance $d[u]$} using a min-heap. Because every future edge has weight $w \ge 0$, no alternate detour through other unsettled vertices (all having distance $\ge d[u]$) can ever shrink $d[u]$ further!

\begin{formulabox}[Edge Relaxation Rule]
$$\text{if } d[u] + w(u, v) < d[v] \implies d[v] = d[u] + w(u, v),\quad \text{push } (d[v],\; v) \text{ to min-heap}$$
\textbf{Read this as:} If stepping from settled node $u$ across edge $(u, v)$ beats the best route previously known to $v$, update $d[v]$ and queue the improved distance (Figure~\ref{fig:graph-dijkstra-relax}).
\end{formulabox}

\begin{watchoutbox}[Watch Out --- Why a Single Negative Edge Breaks Dijkstra]
Consider $3$ vertices $A, B, C$ with edges $A \to B$ (wt $3$), $A \to C$ (wt $5$), and $C \to B$ (wt $-4$). From $A$, the min-heap pops \textbf{$B$ (distance $3$) first} and locks $B$ as finalized! Later, popping $C$ (distance $5$) discovers $A \to C \to B$ with cost $5 + (-4) = \mathbf{1} < 3$, which standard Dijkstra refuses to update (and lazy re-pushing degrades to exponential time on negative chains). Whenever negative weights exist, use \textbf{Bellman-Ford}!
\end{watchoutbox}

\subsection{Minimum Spanning Tree (MST) and Disjoint Set Union (DSU)}

\begin{notationbox}[Symbols Used in MST \& DSU]
MST & Minimum Spanning Tree: $|V| - 1$ acyclic edges linking all vertices at min total weight & Total weight $= 7$ \\
$\text{find}(x)$ & Returns canonical root representative of $x$'s component (with path compression) & Near-$O(1)$ \\
$\text{unite}(x, y)$ & Merges components of $x$ and $y$ by rank/size; returns \texttt{false} if already linked & Prevents cycles \\
$\alpha(V)$ & Inverse Ackermann function: $\alpha(V) \le 4$ for every input up to $10^{80}$ & Practically constant \\
\end{notationbox}

\painbeat Connecting $V$ cities with the cheapest possible fiber-optic network requires avoiding redundant cycles. Testing cycle formation via BFS for every candidate edge would take $O(E \cdot V)$ time---far too slow for $E = 2 \times 10^5$!

\ahabeat Two ideas make \textbf{Kruskal's MST Algorithm} run in $O(E \log E)$:
\begin{enumerate}
    \item \textbf{MST Cut Property:} Processing edges in ascending weight order and accepting every edge that joins two distinct components is provably optimal (each accepted edge is the lightest link crossing the cut between those two components).
    \item \textbf{Disjoint Set Union (DSU):} Tracks connected components as parent-pointer trees. Combining \textbf{Path Compression} (flattening lookup chains directly to the root, Figure~\ref{fig:graph-dsu-compress}) \emph{and} \textbf{Union by Rank/Size} (attaching the shorter tree under the taller root) achieves $O(\alpha(V))$ amortized time per operation!
\end{enumerate}

\subsection{Bellman-Ford and Floyd-Warshall}

\textbf{Bellman-Ford ($O(V \cdot E)$ time, $O(V)$ space):} Any simple shortest path has at most $|V| - 1$ edges. Relaxing \emph{every} edge $|V| - 1$ times propagates optimal distances even across negative edge weights. If a $|V|$-th sweep still relaxes any reachable edge, a \textbf{negative-weight cycle} exists!

\textbf{Floyd-Warshall ($O(V^3)$ time, $O(V^2)$ space):} Computes all-pairs shortest paths when $|V| \le 400$ using 3 nested loops:
\begin{formulabox}[Floyd-Warshall Transition ($k$ MUST Be Outermost!)]
$$\text{For } k = 0 \dots V-1:\quad \text{for } i:\quad \text{for } j:\quad d[i][j] = \min\big(d[i][j],\; d[i][k] + d[k][j]\big)$$
\textbf{Read this as:} After iteration $k$, $d[i][j]$ holds the shortest path from $i$ to $j$ using only intermediate vertices from $\{0, \dots, k\}$.
\end{formulabox}

\begin{calloutbox}{Shortest-Path Algorithm Selector}
\begin{itemize}
    \item \textbf{Unweighted edges ($w = 1$):} \textbf{BFS} in $O(V + E)$.
    \item \textbf{Non-negative weights ($w \ge 0$):} \textbf{Dijkstra} with min-heap in $O((V + E) \log V)$.
    \item \textbf{Negative weights / negative cycle check:} \textbf{Bellman-Ford} in $O(V \cdot E)$.
    \item \textbf{All-pairs shortest paths ($|V| \le 400$):} \textbf{Floyd-Warshall} in $O(V^3)$.
\end{itemize}
\end{calloutbox}

\subsection{Why Naive Graph Exploration Fails}

Brute-force path enumeration fails for three structural reasons:
\begin{enumerate}
    \item \textbf{Factorial Path Explosion:} A complete graph on $V = 20$ nodes contains up to $20! \approx 2.4 \times 10^{18}$ simple paths.
    \item \textbf{Infinite Loops on Cycles:} Traversing without a \texttt{visited} / color state bounces endlessly around cycles until stack overflow.
    \item \textbf{Repeated Pairwise Scans:} Testing connectivity for every pair $(u, v)$ independently costs $O(V^2 (V + E))$; a single DFS/BFS component sweep costs $O(V + E)$.
\end{enumerate}

\begin{example}[Counting Isolated Server Clusters (Connected Components)]
A network has $n = 6$ servers ($0 \dots 5$) with $4$ undirected links: $(0,1), (1,2), (3,4), (4,5)$.
\begin{enumerate}
    \item Initialize \texttt{visited[0..5] = false}, \texttt{clusters = 0}.
    \item Scan $0$ (unvisited): increment \texttt{clusters = 1}; DFS visits $0 \to 1 \to 2$.
    \item Nodes $1$ and $2$ are already visited; skip.
    \item Scan $3$ (unvisited): increment \texttt{clusters = 2}; DFS visits $3 \to 4 \to 5$.
    \item Nodes $4$ and $5$ are already visited. \textbf{Answer:} $\mathbf{2}$ isolated clusters.
\end{enumerate}
\end{example}

\begin{example}[Course Prerequisite Scheduling with Cycle Detection]
Four courses ($0 \dots 3$) have prerequisites $0 \to 1,\; 1 \to 2,\; 2 \to 3,\; 3 \to 1$. Can a student finish all $4$?
\begin{enumerate}
    \item Compute in-degrees: $\deg^-(0) = 0,\; \deg^-(1) = 2,\; \deg^-(2) = 1,\; \deg^-(3) = 1$.
    \item Initialize queue $Q = [0]$, \texttt{processed = 0}.
    \item Pop $0$: \texttt{processed = 1}; decrement $\deg^-(1)$ from $2$ to $1$. No node hits $0$.
    \item Queue is empty with only $1 < 4$ courses processed. Remaining nodes $\{1, 2, 3\}$ form a deadlock cycle $1 \to 2 \to 3 \to 1$. \textbf{Answer:} Impossible.
\end{enumerate}
\end{example}

\begin{example}[Network Packet Propagation Delay via Dijkstra]
Four servers ($1 \dots 4$) have directed latencies $(2 \to 1,\; 1),\; (2 \to 3,\; 1),\; (3 \to 4,\; 1)$. Broadcast starts from server $2$.
\begin{enumerate}
    \item Initialize $d = [\infty, \infty, 0, \infty, \infty]$ (1-indexed), min-heap $\{(0, 2)\}$.
    \item Pop $(0, 2)$: relax $d[1] = 1$, $d[3] = 1$; heap $\{(1, 1), (1, 3)\}$.
    \item Pop $(1, 1)$ (no outgoing edges); pop $(1, 3)$: relax $d[4] = 2$; push $(2, 4)$.
    \item Pop $(2, 4)$: done. All servers reached; broadcast time $= \max(1, 0, 1, 2) = \mathbf{2}$.
\end{enumerate}
\end{example}

\vspace{-4pt}
\begin{example}[Finding the Redundant Connection via DSU]
A 4-node graph starts as a tree and receives edges in order: $(0,1),\; (1,2),\; (2,3),\; (3,1)$. Which edge closes the cycle?
\begin{enumerate}[itemsep=0.5pt, topsep=1pt, parsep=0pt]
    \item Process $(0,1)$: $\text{find}(0) \neq \text{find}(1) \implies$ unite $\{0, 1\}$.
    \item Process $(1,2)$: $\text{find}(1) \neq \text{find}(2) \implies$ unite $\{0, 1, 2\}$.
    \item Process $(2,3)$: $\text{find}(2) \neq \text{find}(3) \implies$ unite $\{0, 1, 2, 3\}$.
    \item Process $(3,1)$: $\text{find}(3) = \text{find}(1)$! Already connected $\implies$ \textbf{$(3, 1)$ is the redundant edge.}
\end{enumerate}
\end{example}

\vspace{-4pt}
\begin{example}[Splitting Four People into Two Conflict-Free Teams (2-Coloring)]
Dislike edges on $\{0, 1, 2, 3\}$: $(0,1), (0,3), (1,2), (2,3)$.
\begin{enumerate}[itemsep=0.5pt, topsep=1pt, parsep=0pt]
    \item Initialize \texttt{color = [-1, -1, -1, -1]}. Set $\texttt{color[0]} = 0$.
    \item Neighbors of $0$ ($1$ and $3$) receive color $1$.
    \item Neighbor $2$ of $1$ receives color $1 - 1 = 0$.
    \item Edge $(3, 2)$ checks $\texttt{color[3]} = 1 \neq \texttt{color[2]} = 0$: valid! Teams: $\{0, 2\}$ and $\{1, 3\}$.
\end{enumerate}
\end{example}

\subsection{Breadth-First Search (Unweighted Shortest Paths)}
Returns a distance vector with $-1$ for unreachable vertices, guarding invalid source indices.

\begin{lstlisting}[caption={Breadth-First Search for unweighted shortest paths}]
#include <cstddef>
#include <queue>
#include <vector>

[[nodiscard]] std::vector<int> breadth_first_search(
    int vertex_count,
    const std::vector<std::vector<int>>& adj,
    int source
) {
    if (vertex_count <= 0 || source < 0 || source >= vertex_count) return {};
    std::vector<int> dist(static_cast<std::size_t>(vertex_count), -1);
    std::queue<int> q;

    dist[static_cast<std::size_t>(source)] = 0;
    q.push(source);

    while (!q.empty()) {
        const int u = q.front();
        q.pop();
        for (int v : adj[static_cast<std::size_t>(u)]) {
            const auto v_idx = static_cast<std::size_t>(v);
            if (dist[v_idx] == -1) {
                dist[v_idx] = dist[static_cast<std::size_t>(u)] + 1;
                q.push(v);
            }
        }
    }
    return dist;
}
\end{lstlisting}

\subsection{2D Grid Shortest Path BFS}
Uses direction offset arrays $\Delta r, \Delta c$ and includes \texttt{<cstddef>} for \texttt{std::size\_t}.

\begin{lstlisting}[caption={2D Grid Shortest Path BFS with 4-directional offsets}]
#include <array>
#include <cstddef>
#include <queue>
#include <utility>
#include <vector>

[[nodiscard]] int shortest_path_binary_grid(const std::vector<std::vector<int>>& grid) {
    if (grid.empty() || grid[0].empty()) return -1;

    const int rows = static_cast<int>(grid.size());
    const int cols = static_cast<int>(grid[0].size());
    if (grid[0][0] == 1 || grid[static_cast<std::size_t>(rows - 1)][static_cast<std::size_t>(cols - 1)] == 1) {
        return -1;
    }

    std::vector<std::vector<int>> dist(
        static_cast<std::size_t>(rows),
        std::vector<int>(static_cast<std::size_t>(cols), -1)
    );
    std::queue<std::pair<int, int>> q;
    constexpr std::array<int, 4> dr{-1, 1, 0, 0};
    constexpr std::array<int, 4> dc{0, 0, -1, 1};

    dist[0][0] = 0;
    q.emplace(0, 0);

    while (!q.empty()) {
        const auto [r, c] = q.front();
        q.pop();
        const auto r_idx = static_cast<std::size_t>(r);
        const auto c_idx = static_cast<std::size_t>(c);
        if (r == rows - 1 && c == cols - 1) return dist[r_idx][c_idx];

        for (std::size_t k = 0; k < 4; ++k) {
            const int nr = r + dr[k];
            const int nc = c + dc[k];
            if (nr >= 0 && nr < rows && nc >= 0 && nc < cols) {
                const auto ur = static_cast<std::size_t>(nr);
                const auto uc = static_cast<std::size_t>(nc);
                if (grid[ur][uc] == 0 && dist[ur][uc] == -1) {
                    dist[ur][uc] = dist[r_idx][c_idx] + 1;
                    q.emplace(nr, nc);
                }
            }
        }
    }
    return -1;
}
\end{lstlisting}

\subsection{Connected Components via DFS}
Paints every disconnected cluster with a unique $0$-based component ID using a C++23 recursive lambda.

\begin{lstlisting}[caption={Connected component labeling via DFS}]
#include <cstddef>
#include <vector>

[[nodiscard]] int label_connected_components(
    int vertex_count,
    const std::vector<std::vector<int>>& adj,
    std::vector<int>& component_id
) {
    if (vertex_count <= 0) {
        component_id.clear();
        return 0;
    }
    component_id.assign(static_cast<std::size_t>(vertex_count), -1);
    int component_count = 0;

    auto dfs = [&](this auto& self, int u, int id) -> void {
        component_id[static_cast<std::size_t>(u)] = id;
        for (int v : adj[static_cast<std::size_t>(u)]) {
            if (component_id[static_cast<std::size_t>(v)] == -1) {
                self(v, id);
            }
        }
    };

    for (int i = 0; i < vertex_count; ++i) {
        if (component_id[static_cast<std::size_t>(i)] == -1) {
            dfs(i, component_count);
            ++component_count;
        }
    }
    return component_count;
}
\end{lstlisting}

\subsection{3-Color Directed Cycle Detection (DFS)}
Colors vertices White ($0$), Gray ($1$), or Black ($2$); returns \texttt{true} immediately upon hitting any Gray ancestor.

\begin{lstlisting}[caption={Directed cycle detection using 3-color DFS}]
#include <cstddef>
#include <cstdint>
#include <vector>

[[nodiscard]] bool has_directed_cycle(
    int vertex_count,
    const std::vector<std::vector<int>>& adj
) {
    if (vertex_count <= 0) return false;
    enum class Color : std::uint8_t { White = 0, Gray = 1, Black = 2 };
    std::vector<Color> color(static_cast<std::size_t>(vertex_count), Color::White);

    auto dfs = [&](this auto& self, int u) -> bool {
        const auto u_idx = static_cast<std::size_t>(u);
        color[u_idx] = Color::Gray;
        for (int v : adj[u_idx]) {
            const auto v_idx = static_cast<std::size_t>(v);
            if (color[v_idx] == Color::Gray) return true; // Back-edge => cycle
            if (color[v_idx] == Color::White && self(v)) return true;
        }
        color[u_idx] = Color::Black;
        return false;
    };

    for (int i = 0; i < vertex_count; ++i) {
        if (color[static_cast<std::size_t>(i)] == Color::White && dfs(i)) {
            return true;
        }
    }
    return false;
}
\end{lstlisting}

\subsection{Topological Sort via Kahn's Algorithm}
Computes in-degrees, peels zero-in-degree vertices via FIFO queue, and returns an empty vector if any cycle remains.

\begin{lstlisting}[caption={Topological sort and cycle detection via Kahn's algorithm}]
#include <cstddef>
#include <queue>
#include <vector>

[[nodiscard]] std::vector<int> topological_sort_kahn(
    int vertex_count,
    const std::vector<std::vector<int>>& adj
) {
    if (vertex_count <= 0) return {};
    std::vector<int> in_degree(static_cast<std::size_t>(vertex_count), 0);
    for (int u = 0; u < vertex_count; ++u) {
        for (int v : adj[static_cast<std::size_t>(u)]) {
            ++in_degree[static_cast<std::size_t>(v)];
        }
    }

    std::queue<int> q;
    for (int i = 0; i < vertex_count; ++i) {
        if (in_degree[static_cast<std::size_t>(i)] == 0) q.push(i);
    }

    std::vector<int> order;
    order.reserve(static_cast<std::size_t>(vertex_count));
    while (!q.empty()) {
        const int u = q.front();
        q.pop();
        order.push_back(u);
        for (int v : adj[static_cast<std::size_t>(u)]) {
            const auto v_idx = static_cast<std::size_t>(v);
            if (--in_degree[v_idx] == 0) q.push(v);
        }
    }

    if (static_cast<int>(order.size()) != vertex_count) return {};
    return order;
}
\end{lstlisting}

\subsection{Dijkstra's Algorithm (\texorpdfstring{\texttt{int64\_t}}{int64\_t} Overflow-Safe)}
Uses \texttt{std::int64\_t} distances with \texttt{INF = max() / 2}, includes \texttt{<functional>} for \texttt{std::greater}, guards \texttt{source} bounds, and discards stale heap entries.

\begin{lstlisting}[caption={Overflow-safe Dijkstra's algorithm using 64-bit distances}]
#include <cstddef>
#include <cstdint>
#include <functional>
#include <limits>
#include <queue>
#include <utility>
#include <vector>

struct WeightedEdge {
    int to;
    std::int64_t weight;
};

[[nodiscard]] std::vector<std::int64_t> dijkstra(
    int vertex_count,
    const std::vector<std::vector<WeightedEdge>>& adj,
    int source
) {
    if (vertex_count <= 0 || source < 0 || source >= vertex_count) return {};
    constexpr std::int64_t INF = std::numeric_limits<std::int64_t>::max() / 2;
    std::vector<std::int64_t> dist(static_cast<std::size_t>(vertex_count), INF);

    using Entry = std::pair<std::int64_t, int>;
    std::priority_queue<Entry, std::vector<Entry>, std::greater<Entry>> pq;

    dist[static_cast<std::size_t>(source)] = 0;
    pq.emplace(0, source);

    while (!pq.empty()) {
        const auto [d, u] = pq.top();
        pq.pop();
        const auto u_idx = static_cast<std::size_t>(u);
        if (d > dist[u_idx]) continue; // Discard stale heap entry

        for (const auto& edge : adj[u_idx]) {
            const auto v_idx = static_cast<std::size_t>(edge.to);
            if (dist[u_idx] + edge.weight < dist[v_idx]) {
                dist[v_idx] = dist[u_idx] + edge.weight;
                pq.emplace(dist[v_idx], edge.to);
            }
        }
    }
    return dist;
}
\end{lstlisting}

\subsection{Bipartite 2-Coloring (BFS Across All Components)}
Checks every connected component so disconnected odd cycles are never missed.

\begin{lstlisting}[caption={Bipartite graph verification via multi-component BFS 2-coloring}]
#include <cstddef>
#include <queue>
#include <vector>

[[nodiscard]] bool is_bipartite(
    int vertex_count,
    const std::vector<std::vector<int>>& adj
) {
    if (vertex_count <= 0) return true;
    std::vector<int> color(static_cast<std::size_t>(vertex_count), -1);
    std::queue<int> q;

    for (int start = 0; start < vertex_count; ++start) {
        if (color[static_cast<std::size_t>(start)] != -1) continue;
        color[static_cast<std::size_t>(start)] = 0;
        q.push(start);

        while (!q.empty()) {
            const int u = q.front();
            q.pop();
            const int u_color = color[static_cast<std::size_t>(u)];
            for (int v : adj[static_cast<std::size_t>(u)]) {
                const auto v_idx = static_cast<std::size_t>(v);
                if (color[v_idx] == -1) {
                    color[v_idx] = 1 - u_color;
                    q.push(v);
                } else if (color[v_idx] == u_color) {
                    return false; // Odd-cycle color conflict
                }
            }
        }
    }
    return true;
}
\end{lstlisting}

\subsection{Disjoint Set Union (DSU) and Kruskal's MST}
Uses C++23 \texttt{std::ranges::iota} in DSU and \texttt{std::ranges::sort} with a member projection in Kruskal's MST, returning \texttt{std::nullopt} if the graph is disconnected.

\begin{lstlisting}[caption={Disjoint Set Union with path compression and union by rank}]
#include <cstddef>
#include <numeric>
#include <utility>
#include <vector>

class DisjointSetUnion {
public:
    explicit DisjointSetUnion(int n)
        : parent_(static_cast<std::size_t>(n > 0 ? n : 0)),
          rank_(static_cast<std::size_t>(n > 0 ? n : 0), 0),
          component_count_(n > 0 ? n : 0) {
        std::ranges::iota(parent_, 0);
    }

    [[nodiscard]] int find(int x) noexcept {
        const auto idx = static_cast<std::size_t>(x);
        if (parent_[idx] == x) return x;
        return parent_[idx] = find(parent_[idx]);
    }

    bool unite(int x, int y) noexcept {
        int rx = find(x);
        int ry = find(y);
        if (rx == ry) return false;

        if (rank_[static_cast<std::size_t>(rx)] < rank_[static_cast<std::size_t>(ry)]) {
            std::swap(rx, ry);
        }
        parent_[static_cast<std::size_t>(ry)] = rx;
        if (rank_[static_cast<std::size_t>(rx)] == rank_[static_cast<std::size_t>(ry)]) {
            ++rank_[static_cast<std::size_t>(rx)];
        }
        --component_count_;
        return true;
    }

    [[nodiscard]] bool connected(int x, int y) noexcept { return find(x) == find(y); }
    [[nodiscard]] int component_count() const noexcept { return component_count_; }

private:
    std::vector<int> parent_;
    std::vector<int> rank_;
    int component_count_;
};
\end{lstlisting}

\begin{lstlisting}[caption={Kruskal's Minimum Spanning Tree using std::ranges::sort and DSU}]
#include <algorithm>
#include <cstddef>
#include <cstdint>
#include <numeric>
#include <optional>
#include <utility>
#include <vector>

struct UndirectedEdge {
    int u;
    int v;
    std::int64_t weight;
};

[[nodiscard]] std::optional<std::int64_t> kruskal_mst(
    int vertex_count,
    std::vector<UndirectedEdge> edges
) {
    if (vertex_count <= 0) return 0;
    if (vertex_count == 1) return 0;

    std::ranges::sort(edges, {}, &UndirectedEdge::weight);

    std::vector<int> parent(static_cast<std::size_t>(vertex_count));
    std::vector<int> rank(static_cast<std::size_t>(vertex_count), 0);
    std::ranges::iota(parent, 0);

    auto find = [&](this auto& self, int x) -> int {
        const auto idx = static_cast<std::size_t>(x);
        return (parent[idx] == x) ? x : (parent[idx] = self(parent[idx]));
    };

    std::int64_t total_weight = 0;
    int edges_used = 0;
    for (const auto& e : edges) {
        int ru = find(e.u);
        int rv = find(e.v);
        if (ru == rv) continue;
        if (rank[static_cast<std::size_t>(ru)] < rank[static_cast<std::size_t>(rv)]) {
            std::swap(ru, rv);
        }
        parent[static_cast<std::size_t>(rv)] = ru;
        if (rank[static_cast<std::size_t>(ru)] == rank[static_cast<std::size_t>(rv)]) {
            ++rank[static_cast<std::size_t>(ru)];
        }
        total_weight += e.weight;
        if (++edges_used == vertex_count - 1) return total_weight;
    }
    return std::nullopt; // Graph is disconnected
}
\end{lstlisting}

\subsection{Bellman-Ford and Floyd-Warshall}
Bellman-Ford returns \texttt{std::nullopt} if any negative-weight cycle is reachable from \texttt{source}; Floyd-Warshall guards against relaxing unreachable \texttt{INF} paths.

\begin{lstlisting}[caption={Bellman-Ford single-source shortest paths with negative-cycle check}]
#include <cstddef>
#include <cstdint>
#include <limits>
#include <optional>
#include <span>
#include <vector>

struct DirectedEdge {
    int u;
    int v;
    std::int64_t weight;
};

[[nodiscard]] std::optional<std::vector<std::int64_t>> bellman_ford(
    int vertex_count,
    std::span<const DirectedEdge> edges,
    int source
) {
    if (vertex_count <= 0 || source < 0 || source >= vertex_count) return std::nullopt;
    constexpr std::int64_t INF = std::numeric_limits<std::int64_t>::max() / 2;
    std::vector<std::int64_t> dist(static_cast<std::size_t>(vertex_count), INF);
    dist[static_cast<std::size_t>(source)] = 0;

    for (int iter = 0; iter < vertex_count - 1; ++iter) {
        bool updated = false;
        for (const auto& e : edges) {
            const auto u = static_cast<std::size_t>(e.u);
            const auto v = static_cast<std::size_t>(e.v);
            if (dist[u] != INF && dist[u] + e.weight < dist[v]) {
                dist[v] = dist[u] + e.weight;
                updated = true;
            }
        }
        if (!updated) break; // Converged early
    }

    for (const auto& e : edges) {
        const auto u = static_cast<std::size_t>(e.u);
        const auto v = static_cast<std::size_t>(e.v);
        if (dist[u] != INF && dist[u] + e.weight < dist[v]) {
            return std::nullopt; // Reachable negative-weight cycle detected
        }
    }
    return dist;
}
\end{lstlisting}

\begin{lstlisting}[caption={Floyd-Warshall all-pairs shortest paths (k-outermost loop)}]
#include <algorithm>
#include <cstddef>
#include <cstdint>
#include <limits>
#include <vector>

[[nodiscard]] std::vector<std::vector<std::int64_t>> floyd_warshall(
    std::vector<std::vector<std::int64_t>> dist
) {
    constexpr std::int64_t INF = std::numeric_limits<std::int64_t>::max() / 2;
    const std::size_t n = dist.size();

    for (std::size_t k = 0; k < n; ++k) {
        for (std::size_t i = 0; i < n; ++i) {
            if (dist[i][k] == INF) continue;
            for (std::size_t j = 0; j < n; ++j) {
                if (dist[k][j] == INF) continue;
                dist[i][j] = std::min(dist[i][j], dist[i][k] + dist[k][j]);
            }
        }
    }
    return dist;
}
\end{lstlisting}

\section{Problem Pattern Recognition}
% ============================================================================

\subsection*{Step 1: What Does the Problem Ask For?}
\begin{itemize}
    \item \textbf{Minimum steps / shortest path:} Unweighted $\implies$ \textbf{BFS}; non-negative weights $\implies$ \textbf{Dijkstra}; negative weights $\implies$ \textbf{Bellman-Ford}; all pairs ($V \le 400$) $\implies$ \textbf{Floyd-Warshall}.
    \item \textbf{Islands / reachability / component count:} \textbf{DFS} or \textbf{BFS} with a visited array.
    \item \textbf{Prerequisite order / deadlock check:} \textbf{Kahn's Topological Sort} or \textbf{3-Color DFS}.
    \item \textbf{Incremental merging / redundant edge:} \textbf{DSU} with path compression + rank.
    \item \textbf{Two conflict-free teams:} \textbf{Bipartite 2-Coloring}.
    \item \textbf{Cheapest network connecting all nodes:} \textbf{Kruskal's MST}.
\end{itemize}

\subsection*{Step 2: What Is the Key Constraint?}
\begin{itemize}
    \item \textbf{Uniform edge weight ($w = 1$):} Prefer $O(V + E)$ BFS over $O((V + E) \log V)$ Dijkstra.
    \item \textbf{Directed vs.\ undirected:} Directed cycle detection needs 3 colors; undirected needs parent check or DSU.
    \item \textbf{Negative weights:} Never use Dijkstra; switch to Bellman-Ford (or Floyd-Warshall for small all-pairs).
\end{itemize}

\subsection*{Step 3: Constraint Thresholds}
\begin{itemize}
    \item $V, E \le 10^5$: Must stay $O(V + E)$ or $O((V + E) \log V)$ with an Adjacency List.
    \item $V \le 400$: Adjacency Matrix + $O(V^3)$ Floyd-Warshall fits easily.
    \item $V \le 20$: Exponential Bitmask DP (Module 06) is viable.
\end{itemize}

Floyd-Warshall & $O(V^3)$ & $O(V^2)$ & All-pairs shortest paths ($V \le 400$) \\
Bipartite 2-Coloring & $O(V + E)$ & $O(V)$ & Splitting into 2 conflict-free sets \\

\end{tabularx}\endgroup

\section{Glossary}
% ============================================================================

\subsection*{Core Concepts}
\begin{itemize}
    \item \textbf{Adjacency List:} Vector of neighbor lists; $O(V + E)$ space, optimal default for sparse graphs.
    \item \textbf{Adjacency Matrix:} $V \times V$ grid of edge weights; $O(1)$ edge lookup, $O(V^2)$ space ($V \le 500$).
    \item \textbf{Back-Edge:} Directed edge encountered during DFS pointing to a Gray ancestor currently on the call stack.
    \item \textbf{Bipartite Graph:} Undirected graph partitionable into two independent sets; contains no odd cycles.
    \item \textbf{Connected Component:} Maximal subgraph where every pair of vertices is linked by a path.
    \item \textbf{Directed Acyclic Graph (DAG):} Directed graph with zero cycles; always admits a topological order.
    \item \textbf{Disjoint Set Union (DSU):} Partition structure supporting near-$O(1)$ \texttt{find} and \texttt{unite}.
    \item \textbf{Edge List:} Flat array of $(u, v, w)$ edge tuples; $O(E)$ space, ideal for Kruskal and Bellman-Ford.
    \item \textbf{Minimum Spanning Tree (MST):} Acyclic subgraph of $|V| - 1$ edges connecting all vertices at minimum weight.
    \item \textbf{Path Compression:} Flattening DSU parent pointers directly to the root during \texttt{find}.
    \item \textbf{Relaxation:} Testing if $d[u] + w(u, v) < d[v]$ and updating $d[v]$ to the shorter path.
    \item \textbf{Topological Order:} Linear vertex order where every directed edge $u \to v$ places $u$ before $v$.
    \item \textbf{Union by Rank / Size:} Attaching the shorter DSU tree beneath the taller root to bound height.
\end{itemize}

\subsection*{Mathematical Symbols}
\begin{itemize}
    \item $G = (V, E),\; |V|,\; |E|$: Graph, vertex count, and edge count.
    \item $\deg(v),\; \deg^-(v),\; \deg^+(v)$: Undirected degree, directed in-degree, and directed out-degree of vertex $v$.
    \item $u \to v,\; w(u, v)$: Directed edge from $u$ to $v$ and its numerical weight.
    \item $d[u]$: Shortest tentative distance from source to vertex $u$.
    \item $\alpha(V)$: Inverse Ackermann function ($\alpha(V) \le 4$ for all practical inputs).
    \item $\infty$ (\texttt{INF}): Overflow-safe unreachable sentinel (\texttt{std::numeric\_limits<std::int64\_t>::max() / 2}).
\end{itemize}

\noindent
Solve these six mixed cold-start drills on scratch paper \emph{without} looking back at the chapter. Each drill tests a different thinking mode with zero section hints.

\begin{tryitbox}{Triage}{Picking the Right Graph Tool}{ex9}
For each disguised problem below, name the exact graph algorithm and asymptotic time complexity:
\begin{enumerate}
    \item Transform \texttt{"hit"} into \texttt{"cog"} changing one letter at a time through a $5{,}000$-word dictionary in minimum steps.
    \item Connect $10{,}000$ data centers using a subset of $50{,}000$ priced fiber links at minimum total cost.
    \item Find shortest travel costs between \emph{every} pair of $250$ airports where some legs offer rebates (negative costs, no negative cycles).
\end{enumerate}
\end{tryitbox}

\begin{tryitbox}{Trace}{Bellman-Ford Negative-Cycle Detection}{ex10}
Trace Bellman-Ford from source $0$ on $V = 3$ vertices with directed edges $0 \to 1$ ($+2$), $1 \to 2$ ($+3$), and $2 \to 1$ ($-6$). Write \texttt{dist[0..2]} after Sweep $1$, after Sweep $2$ ($V - 1$), and show which edge still relaxes on Sweep $3$ ($V$-th check).
\end{tryitbox}

\begin{tryitbox}{Debug}{Why Repeated BFS Times Out on Multi-Fire Grids}{ex11}
On a $500 \times 500$ grid containing $K = 10{,}000$ starting fire cells, a programmer runs one separate BFS per fire cell to compute every cell's distance to the nearest fire. Estimate the operation count of that approach, explain why it times out, and show how \textbf{Multi-Source BFS} fixes it in a single $O(R \cdot C)$ pass.
\end{tryitbox}

\begin{tryitbox}{Twist}{Lexicographically Smallest Topological Order}{ex12}
Standard Kahn's algorithm uses \texttt{std::queue<int>} and returns \emph{any} valid topological order. What single container swap guarantees the \textbf{lexicographically smallest} valid topological order, and how does the time complexity change?
\end{tryitbox}

\begin{tryitbox}{Edge Cases}{Disconnected Graphs and Negative INF Traps}{ex13}
State the exact bug that occurs when each guard below is omitted:
\begin{enumerate}
    \item Running Bipartite 2-Coloring BFS only from vertex $0$ on a disconnected graph.
    \item Returning \texttt{total\_weight} at the end of Kruskal's loop without checking \texttt{edges\_used == V - 1}.
    \item Evaluating \texttt{dist[i][k] + dist[k][j]} in Floyd-Warshall without checking \texttt{dist[i][k] != INF} when negative edges exist.
\end{enumerate}
\end{tryitbox}

\begin{tryitbox}{Derive}{Tree Edge Count \& Worst-Case Unoptimized DSU}{ex14}
\begin{enumerate}
    \item Prove briefly by induction that every tree on $V \ge 1$ vertices has exactly $V - 1$ edges.
    \item Construct a sequence of $N - 1$ naive DSU unions (without rank/size or path compression) that builds a chain of height $N - 1$, making $M$ calls to \texttt{find(0)} cost $\Theta(M \cdot N)$ time.
\end{enumerate}
\end{tryitbox}

\section*{Solutions to Pen-and-Paper Exercises}
\addcontentsline{toc}{section}{Solutions to Pen-and-Paper Exercises}
\markboth{Solutions to Pen-and-Paper Exercises}{}
% ============================================================================

\begin{enumerate}[itemsep=2pt]
    \item \label{sol:ex1}\textbf{Exercise 1 (Derive) --- Handshaking Lemma \& Memory Budget:}
    \textbf{(1)} $\sum \deg(v) = 2|E| = \mathbf{500{,}000}$; average degree $= 500{,}000 / 100{,}000 = \mathbf{5.0}$.
    \textbf{(2)} Adjacency Matrix: $10^{10} \times 4\text{ B} = \mathbf{40\text{ GB}}$ (OOM!). Adjacency List: $500{,}000 \times 4\text{ B} \approx 2\text{ MB}$ of edge ints plus $100{,}000$ vector headers ($\sim 2.4\text{ MB}$) $\approx \mathbf{4.4\text{ MB}}$.
    \trapnote{Forgetting that each undirected edge is stored \emph{twice} in an adjacency list (once in \texttt{adj[u]} and once in \texttt{adj[v]}).}

    \item \label{sol:ex2}\textbf{Exercise 2 (Trace) --- BFS vs.\ DFS Visit Order:}
    \textbf{(1) BFS from $0$:} Visit order $\mathbf{0, 1, 2, 3, 4, 5}$; $\texttt{dist[0..5]} = \mathbf{[0, 1, 1, 2, 2, 2]}$ (reaches $5$ in $2$ hops via $0-2-5$).
    \textbf{(2) Recursive DFS from $0$:} Visit order $\mathbf{0, 1, 3, 4, 5, 2}$ (dives $0 \to 1 \to 4 \to 5$, reaching $5$ in $3$ hops instead of $2$!).
    \trapnote{Assuming DFS finds shortest paths in general graphs---DFS only gives unique simple paths on trees, never shortest paths on cyclic graphs.}

    \item \label{sol:ex3}\textbf{Exercise 3 (Debug) --- False-Positive Cycle on Diamond DAG:}
    DFS walks $0 \to 1 \to 3$, marking $0, 1, 3$ visited, unwinds back to $0$, then explores $0 \to 2$ and inspects edge $\mathbf{2 \to 3}$. Because $3$ is already \texttt{visited}, the buggy 2-state check falsely reports a cycle even though $3$ is finished (\textbf{Black}), not active (\textbf{Gray}).
    \trapnote{Using a 2-state boolean \texttt{visited} array for directed cycle detection instead of 3-color (White/Gray/Black) DFS.}

    \item \label{sol:ex4}\textbf{Exercise 4 (Trace) --- Kahn's Algorithm on a 5-Node DAG:}
    Initial $\deg^- = [0, 0, 2, 1, 2]$; $Q = [0, 1]$. Pop $0$ ($\deg^-[2] \to 1$); pop $1$ ($\deg^-[2] \to 0,\; \deg^-[3] \to 0$, $Q = [2, 3]$); pop $2$ ($\deg^-[4] \to 1$); pop $3$ ($\deg^-[4] \to 0$, $Q = [4]$); pop $4$. Topological order: $\mathbf{[0, 1, 2, 3, 4]}$.
    \trapnote{Enqueuing vertex $2$ after popping $0$ when $\deg^-[2]$ only dropped from $2$ to $1$---only push a node when its in-degree hits \emph{zero}.}

    \item \label{sol:ex5}\textbf{Exercise 5 (Debug) --- Breaking Dijkstra with One Negative Edge:}
    Example: $A \to B$ (wt $2$), $A \to C$ (wt $4$), $C \to B$ (wt $-5$). From $A$, $d[B] = 2 < d[C] = 4$, so Dijkstra pops and locks $B$ at $2$. Later, popping $C$ ($4$) finds $A \to C \to B$ of weight $4 - 5 = \mathbf{-1}$, which locked Dijkstra misses. Requiring $d[B] < d[C]$ initially is essential; otherwise $C$ would pop first and relax $B$ before $B$ is finalized!
    \trapnote{Choosing $w(A, C) < w(A, B)$ in a counterexample---that makes Dijkstra pop $C$ first and accidentally find the right answer!}

    \item \label{sol:ex6}\textbf{Exercise 6 (Trace) --- Bipartite 2-Coloring on $C_5$:}
    With $(4, 0)$: $\texttt{color[0]} = 0 \implies \texttt{color[1]} = \texttt{color[4]} = 1 \implies \texttt{color[2]} = \texttt{color[3]} = 0$. Edge $\mathbf{(2, 3)}$ connects two Color-$0$ nodes $\implies$ \textbf{Not bipartite!} Deleting $(4, 0)$ leaves path $0-1-2-3-4$ with valid 2-coloring $\mathbf{[0, 1, 0, 1, 0]}$.
    \trapnote{Forgetting to check edges between two already-colored vertices when both sit on the same BFS wavefront level.}

    \item \label{sol:ex7}\textbf{Exercise 7 (Twist) --- Maximum Spanning Tree via Kruskal:}
    Sort edges in \textbf{descending} weight order (pass \texttt{std::greater\{\}} to \texttt{std::ranges::sort} with projection \texttt{\&UndirectedEdge::weight}). Negating all edge weights turns Maximum Spanning Tree into standard MST, so the Cut Property holds identically.
    \trapnote{Reversing the \texttt{find(u) != find(v)} cycle check instead of the sort comparator---the spanning-tree cycle rule never changes!}

    \item \label{sol:ex8}\textbf{Exercise 8 (Debug) --- Three Classic Graph Code Bugs:}
    \textbf{(1)} Two large positive weights (or \texttt{INF + w}) overflow 32-bit \texttt{int} into negative values (UB), corrupting \texttt{std::min} / heap order.
    \textbf{(2)} Putting \texttt{k} innermost computes $d[i][j]$ before $d[i][k]$ and $d[k][j]$ have finished exploring intermediate vertices, missing multi-hop shortcuts.
    \textbf{(3)} Expanding stale heap entries re-scans adjacency lists repeatedly, degrading worst-case runtime to $O(V \cdot E)$.
    \trapnote{Thinking \texttt{INT\_MAX} is safe as long as you check \texttt{dist[u] != INF}---valid multi-hop paths can still sum past $2.1 \times 10^9$!}

    \item \label{sol:ex9}\textbf{Exercise 9 (Triage) --- Picking the Right Graph Tool:}
    \textbf{(1)} Unweighted \textbf{BFS} in $O(V + E)$ (each 1-letter edit costs $1$).
    \textbf{(2)} \textbf{Kruskal's MST + DSU} in $O(E \log E)$.
    \textbf{(3)} \textbf{Floyd-Warshall} in $O(V^3)$ ($250^3 \approx 1.56 \times 10^7$, handles negative edges without negative cycles).
    \trapnote{Reaching for Dijkstra on (3) because it asks for shortest paths---negative rebates immediately disqualify Dijkstra.}

    \item \label{sol:ex10}\textbf{Exercise 10 (Trace) --- Bellman-Ford Negative Cycle:}
    Init: $[0, \infty, \infty]$. Sweep 1: $0 \to 1$ ($2$), $1 \to 2$ ($5$), $2 \to 1$ ($-1$) $\implies [0, -1, 5]$. Sweep 2: $1 \to 2$ ($2$), $2 \to 1$ ($-4$) $\implies [0, -4, 2]$. Sweep 3 ($V$-th): edge $\mathbf{1 \to 2}$ relaxes $d[2]$ from $2$ to $-4 + 3 = -1 \implies$ \textbf{Negative cycle detected} ($1 \to 2 \to 1$, net $-3$).
    \trapnote{Stopping after $V - 1$ sweeps without running the $V$-th verification pass when negative cycles are possible.}

    \item \label{sol:ex11}\textbf{Exercise 11 (Debug) --- Multi-Source BFS vs.\ Repeated BFS:}
    Running $10{,}000$ separate BFS passes on $250{,}000$ cells performs up to $2.5 \times 10^9$ operations (TLE). \textbf{Multi-Source BFS} pushes \emph{all} $K$ fire cells into one queue at \texttt{dist = 0} before the loop begins, computing every cell's nearest fire in a single $O(R \cdot C) \approx 2.5 \times 10^5$ pass!
    \trapnote{Thinking BFS can only have a single starting vertex---any set of distance-$0$ sources preserves the FIFO wavefront invariant.}

    \item \label{sol:ex12}\textbf{Exercise 12 (Twist) --- Lexicographically Smallest Topological Order:}
    Swap \texttt{std::queue<int>} for a min-heap \texttt{std::priority\_queue<int, std::vector<int>, std::greater<int>>} so the smallest available vertex ID always pops next. Time complexity rises from $O(V + E)$ to $\mathbf{O((V + E) \log V)}$.
    \trapnote{Using the default \texttt{std::priority\_queue<int>} without \texttt{std::greater<int>}---that is a \emph{max}-heap and returns the lexicographically largest order!}

    \item \label{sol:ex13}\textbf{Exercise 13 (Edge Cases) --- Disconnected Graphs \& Negative INF:}
    \textbf{(1)} Misses any odd cycle sitting inside a component unreachable from vertex $0$ (wrongly returns \texttt{true}).
    \textbf{(2)} Returns the weight of a disconnected spanning \emph{forest} instead of signaling that no spanning tree exists.
    \textbf{(3)} Adding a negative edge to \texttt{INF} produces $\texttt{INF} - w < \texttt{INF}$, falsely turning an unreachable pair into a ``valid'' path of cost $\approx \infty$!
    \trapnote{Testing graph algorithms only on a single connected component with positive weights.}

    \item \label{sol:ex14}\textbf{Exercise 14 (Derive) --- Tree Edge Count \& Worst-Case DSU:}
    \textbf{(1)} Base $V = 1$: $0 = 1 - 1$ edges. Every tree with $V \ge 2$ has a leaf ($\deg = 1$); deleting that leaf and its single edge yields a tree on $V - 1$ vertices with $(V - 2)$ edges by induction, giving $(V - 2) + 1 = \mathbf{V - 1}$.
    \textbf{(2)} Attaching the existing chain's root under each new singleton (\texttt{parent[0] = 1, parent[1] = 2, ..., parent[N-2] = N-1}) builds chain $0 \to 1 \to \dots \to N - 1$; calling \texttt{find(0)} $M$ times walks $N - 1$ hops every time ($\Theta(M \cdot N)$).
    \trapnote{Claiming Path Compression alone gives $O(\alpha(N))$---without Union by Rank/Size, worst-case amortized cost degrades to $O(\log N)$ per operation.}
\end{enumerate}
