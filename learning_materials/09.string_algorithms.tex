% ============================================================================
\section{Foundations of String Processing}
% ============================================================================

To a computer, a string is just a contiguous array of small integers (typically ASCII bytes). Because characters have numeric codes, we can index arrays with \texttt{c - 'a'}, build polynomials out of them, and exploit overlapping structure to avoid re-scanning text.

\subsection{Substrings, Subsequences, Prefixes, Suffixes, and Borders}

Misreading one word in a string prompt sends you down the wrong algorithm family. Keep these five definitions razor-sharp:

\begin{itemize}
    \item \textbf{Substring:} A \emph{contiguous} slice $S[l \dots r]$. For $S = \text{``apple''}$, \texttt{"app"} and \texttt{"ppl"} are substrings, but \texttt{"ape"} is not. A length-$N$ string has $N(N + 1)/2$ non-empty substrings.
    \item \textbf{Subsequence:} Formed by deleting zero or more characters \emph{without} reordering the rest (\texttt{"ape"} is a subsequence of \texttt{"apple"}). Subsequence problems usually belong to Dynamic Programming (Module~06), not string matching.
    \item \textbf{Prefix:} A substring anchored at index $0$, i.e., $S[0 \dots k]$.
    \item \textbf{Suffix:} A substring anchored at the end, i.e., $S[k \dots N - 1]$.
    \item \textbf{Border:} A string that is \emph{both} a \textbf{proper} prefix (not the whole string) and a suffix of $S$. For \texttt{"ababa"}, the borders are \texttt{"a"} and \texttt{"aba"}. Borders are the secret engine behind both KMP and string periodicity!
\end{itemize}

\subsection{Strings in Modern C++: \texttt{std::string} vs.\ \texttt{std::string\_view}}

Slicing a \texttt{std::string} with \texttt{s.substr(l, len)} allocates a brand-new heap buffer and copies $O(\text{len})$ characters. Calling \texttt{substr} inside a loop over $N$ indices silently turns an $O(N)$ idea into $O(N^2)$!

\begin{calloutbox}{Zero-Copy Slices With \texttt{std::string\_view}}
Pass read-only strings by value as \texttt{std::string\_view} (just a pointer + length, 16 bytes). Calling \texttt{sv.substr(l, len)}, \texttt{sv.remove\_prefix(k)}, or \texttt{sv.remove\_suffix(k)} runs in strictly $O(1)$ time with zero allocations.
\end{calloutbox}

\begin{watchoutbox}[Watch Out --- Dangling \texttt{std::string\_view}]
A \texttt{std::string\_view} does \emph{not} own its characters. Never return a \texttt{std::string\_view} pointing into a temporary or local \texttt{std::string} that gets destroyed when the function exits---always ensure the backing string outlives the view.
\end{watchoutbox}

\subsection{Polynomial Rolling Hash and Double Hashing (Rabin-Karp)}

\painbeat Checking whether two length-$L$ substrings are equal character by character takes $O(L)$ time. Sliding a length-$L$ pattern across a length-$N$ text takes $O(N \cdot L)$ time, which times out on $N = 10^5, L = 5 \times 10^4$.

\ahabeat Treat a string like a base-$B$ integer! Just as \texttt{"234"} in base $10$ equals $2 \cdot 10^2 + 3 \cdot 10 + 4$, map each letter to $1 \dots 26$ and evaluate the polynomial modulo a large prime $M$. When a window slides right by one character, you evict the leftmost term, multiply by $B$, and add the new rightmost character---updating the entire fingerprint in $O(1)$!

\examplebeat Hashing \texttt{"cat"} with $B = 31$, $M = 10^9 + 7$, and mapping $\text{'a'} \to 1, \text{'b'} \to 2, \text{'c'} \to 3, \text{'t'} \to 20$:
\begin{enumerate}
    \item $H(\text{``c''}) = 3$.
    \item $H(\text{``ca''}) = (3 \times 31 + 1) \bmod M = 94$.
    \item $H(\text{``cat''}) = (94 \times 31 + 20) \bmod M = 2{,}934$.
\end{enumerate}

Better yet, precompute \textbf{prefix hashes} $H[0] = 0$, $H[i + 1] = (H[i] \cdot B + \text{val}(S[i])) \bmod M$, and powers $P[k] = B^k \bmod M$. Then \emph{any} half-open substring $S[l \dots r)$ can be hashed in $O(1)$ time (just like a prefix sum, shifted by $B^{r - l}$):

\begin{formulabox}[O(1) Prefix Rolling Hash Query for $S[l \dots r)$]
\[
    \text{hash}(S[l \dots r)) = \Bigl(H[r] - H[l] \cdot B^{r - l}\Bigr) \bmod M
\]
\textbf{Read this as:} Subtract the left prefix shifted up to align with $H[r]$; always add $M$ before taking $\bmod\, M$ in C++ to prevent negative remainders.
\end{formulabox}

\begin{watchoutbox}[Watch Out --- Two Classic Rolling Hash Traps]
\begin{enumerate}
    \item \textbf{Never map \texttt{'a' $\to$ 0}:} If \texttt{'a'} has value $0$, then \texttt{"a"}, \texttt{"aa"}, and \texttt{"aaa"} all hash to $0$! Always map \texttt{c - 'a' + 1} (values $1 \dots 26$).
    \item \textbf{Single hash fails at $N = 10^5$:} Even without adversarial tests, comparing $10^5$ substring hashes under a single modulus $M = 10^9 + 7$ collides with $99.3\%$ probability by the Birthday Paradox. Always use \textbf{Double Hashing} (Figure~\ref{fig:rabin_karp_rolling}).
\end{enumerate}
\end{watchoutbox}

\subsection{The KMP Algorithm and Prefix Function ($\pi$-Array)}

\painbeat Suppose you search for $P = \text{``ABABC''}$ inside $T = \text{``ABABABC''}$. After matching \texttt{"ABAB"} ($j = 4$), you hit a mismatch: $T[4] = \text{'A'} \neq P[4] = \text{'C'}$. A naive loop throws away everything it learned and rewinds $T$ back to index $1$!

\ahabeat Look closely at the characters you \emph{already} matched: $T[0 \dots 3] = P[0 \dots 3] = \text{``ABAB''}$. Its longest border is \texttt{"AB"} (length $\pi[3] = 2$). That means the suffix $T[2 \dots 3] = \text{``AB''}$ \emph{already matches} the prefix $P[0 \dots 1] = \text{``AB''}$! So you slide the pattern forward so $P[2]$ sits under $T[4]$---zero rewinding of the text pointer $i$!

\textbf{Why \texttt{j = pi[j - 1]} Never Skips a Valid Match:} Any valid alignment of $P$ ending right before $i$ must have its matched prefix equal to a suffix of $P[0 \dots j - 1]$---i.e., a \emph{border} of $P[0 \dots j - 1]$. Since $\pi[j - 1]$ is the \emph{longest} border, jumping straight to $j \leftarrow \pi[j - 1]$ tries the next longest valid candidate without skipping any possible match.

\begin{formulabox}[KMP Prefix Function ($\pi$-Array) \& Exact Periodicity Test]
\[
    \pi[i] = \max\Bigl\{\, k \in [0, i] \;:\; S[0 \dots k - 1] = S[i - k + 1 \dots i] \,\Bigr\} \qquad (\pi[0] = 0)
\]
\textbf{Read this as:} $\pi[i]$ is the length of the longest proper prefix of $S[0 \dots i]$ that matches its own suffix. The shortest repeating block candidate has length $p = N - \pi[N - 1]$; $S$ is an exact repetition of a smaller block iff $p < N$ and $N \bmod p = 0$.
\end{formulabox}

\subsection{The Z-Algorithm ($Z$-Array vs.\ $\pi$-Array)}

\painbeat KMP tells you the longest border \emph{ending} at index $i$. What if a problem instead asks, for every suffix starting at index $i$, how many characters it shares with the start of the string?

\ahabeat Maintain the rightmost substring window $[L, R]$ discovered so far that matches the prefix $S[0 \dots R - L]$ (called the \textbf{Z-box}). When computing $Z[i]$:
\begin{enumerate}
    \item If $i \le R$, index $i$ lies inside a known copy of the prefix! Mirror $i$ back to $k = i - L$. You immediately get $Z[i] \ge \min(R - i + 1, Z[k])$ characters for \emph{free} without comparing a single character.
    \item Extend $Z[i]$ greedily while $S[Z[i]] == S[i + Z[i]]$. Whenever $i + Z[i] - 1 > R$, update $[L, R] \leftarrow [i, i + Z[i] - 1]$.
\end{enumerate}

Because every successful character comparison strictly increases $R$ (and $R < N$), the total work across all $N$ indices is strictly $O(N)$!

\examplebeat For $S = \text{``aabxaab''}$ ($Z[0] = 0$ by matching convention): $Z = [0, 1, 0, 0, 3, 1, 0]$. At $i = 4$, we match \texttt{"aab"} and set $[L, R] = [4, 6]$. At $i = 5 \le 6$, mirroring to $k = 5 - 4 = 1$ gives $Z[5] = \min(6 - 5 + 1, Z[1]) = \min(2, 1) = 1$ in $O(1)$.

\begin{formulabox}[Z-Function Definition \& Pattern Matching Trick]
\[
    Z[i] = \text{length of the longest common prefix of } S \text{ and } S[i \dots N - 1]
    \qquad (i \ge 1;\; Z[0] = 0 \text{ or } N)
\]
\textbf{Read this as:} To find all occurrences of $P$ in $T$, compute $Z$ on $P + \text{`\#'} + T$ (where \texttt{'\#'} appears in neither string). Every index $i$ with $Z[i] = |P|$ marks a match at text index $i - |P| - 1$.
\end{formulabox}

\subsection{Tries (Prefix Trees) and the Bitwise Trie Bonus}

\painbeat Suppose you store $W = 10^5$ words in a dictionary and receive $10^5$ queries asking ``does \emph{any} word start with prefix \texttt{"ca"}?'' Scanning the list takes $O(W \cdot L)$ per query, and a hash table can only answer \emph{exact} whole-word lookups unless you hash every prefix of every word.

\ahabeat Merge words that share common prefixes into a single rooted tree where every edge carries one character! Walking down the edges \texttt{'c'} $\to$ \texttt{'a'} checks prefix existence in $O(L)$ steps---completely independent of whether the dictionary has $10$ words or $10{,}000{,}000$ words.

\textbf{Flat Vector Pool vs.\ Pointer Trees:} Avoid heap-allocating individual nodes with \texttt{new TrieNode*}. Storing all nodes inside a single \texttt{std::vector<TrieNode>} and referencing children by integer indices (\texttt{-1} for missing) keeps nodes packed contiguously in CPU cache and frees everything automatically when the vector goes out of scope (Figure~\ref{fig:trie_vector_pool}).

\subsection{Palindromes: Expand Around Center \& Manacher's Algorithm}

\painbeat Checking whether every substring $S[l \dots r]$ is a palindrome takes $O(N^3)$ time. Expanding outward from every center ($N$ single-character odd centers + $N - 1$ gap even centers) drops this to $O(N^2)$ time and $O(1)$ space---great for $N \le 3{,}000$, but still $O(N^2)$ on \texttt{"aaaa\dots a"} when $N = 10^5$.

\ahabeat \textbf{Manacher's Algorithm} achieves $O(N)$ worst-case time via two ideas:
\begin{enumerate}
    \item \textbf{Unify odd and even lengths:} Insert \texttt{'\#'} between every pair of characters and at both ends (e.g., \texttt{"abba"} $\to$ \texttt{"\#a\#b\#b\#a\#"}). Now \emph{every} palindrome has odd length in the transformed string $T$, and its radius $P[i]$ (characters extending right of $i$) equals the \textbf{exact length} of the palindrome in $S$!
    \item \textbf{Mirror inside the rightmost palindrome:} Track the center $C$ and right edge $R$ of the palindrome reaching farthest right. For any $i < R$, its mirror index is $i' = 2C - i$. Symmetry guarantees $P[i] \ge \min(R - i, P[i'])$ before expanding outward!
\end{enumerate}

\examplebeat For $S = \text{``abba''}$, $T = \text{``\#a\#b\#b\#a\#''}$ has radii $P = [0, 1, 0, 1, \mathbf{4}, 1, 0, 1, 0]$. At center $i = 4$ (\texttt{'\#'}), radius $P[4] = 4$ matches length $4$ (\texttt{"abba"}) starting at $(i - P[i])/2 = (4 - 4)/2 = 0$.

\begin{formulabox}[Manacher's Mirror Rule \& Index Mapping]
\[
    i' = 2C - i, \qquad
    P[i] \ge \min\bigl(R - i,\; P[i']\bigr) \text{ when } i < R, \qquad
    \text{start in } S = \frac{i - P[i]}{2},\quad \text{length} = P[i]
\]
\textbf{Read this as:} Every extension step beyond $R$ strictly advances $R$, so Manacher runs in strictly $O(N)$ time and $O(N)$ space.
\end{formulabox}

    \item Using Expand Around Center, count \emph{all} palindromic substrings (length $\ge 1$) in \texttt{"aaa"} and in \texttt{"ababa"}.
    \item In $T = \text{``\#a\#b\#a\#b\#a\#''}$, suppose $C = 5$ has right boundary $R = 10$ and $P[3] = 3$. What lower bound does Manacher's mirror formula immediately give at $i = 7$ before any comparisons?
\end{enumerate}
\end{tryitbox}

\subsection{Concatenation With a Sentinel (\texttt{P + '\#' + T} and \texttt{S + '\#' + rev(S)})}

Many disguised string problems reduce to a single call to KMP or Z-Algorithm by gluing two strings together with a sentinel character \texttt{'\#'} that never appears in the alphabet:
\begin{itemize}
    \item \textbf{All matches of $P$ in $T$:} Run Z-Algorithm on $P + \text{`\#'} + T$; matches occur wherever $Z[i] == |P|$.
    \item \textbf{String rotation test:} Is $B$ a cyclic rotation of $A$ (with $|A| = |B|$)? Simply test whether $B$ occurs inside $A + A$ in $O(N)$!
    \item \textbf{Longest palindromic prefix (Shortest Palindrome by Prepending):} Run KMP on $S + \text{`\#'} + \operatorname{rev}(S)$. The final entry $\pi[\text{end}]$ equals the length of the longest prefix of $S$ that reads the same backward!
\end{itemize}

\subsection{Binary Search on Length + Double Rolling Hash}

\painbeat Finding the \textbf{longest substring that appears at least twice} in a length-$10^5$ string (or longest common substring of two strings) cannot check all $O(N^2)$ substrings.

\ahabeat Existence is \textbf{monotonic in length $L$}: if a repeated substring of length $L$ exists, then one of length $L - 1$ also exists (just chop off the last character). Binary search $L \in [0, N]$; for each candidate $L$, hash every length-$L$ window in $O(N)$ using \texttt{DoubleHash} and insert the 64-bit combined pair into an \texttt{unordered\_set}. Total time: $O(N \log N)$!

Find the smallest counterexample $(P, T)$ where this reports a false match or returns $Z[i] > |P|$ by crossing the boundary, and explain why \texttt{'\#'} fixes it.
\end{tryitbox}

\section{Worked Examples}

Work through these five complete traces by hand; every step can be reproduced on scratch paper.

\begin{example}[Shortest Repeating Period via KMP]
Determine whether $S_1 = \text{``ABABAB''}$ and $S_2 = \text{``ABABA''}$ are exact repetitions of a smaller substring.
\begin{enumerate}
    \item \textbf{For $S_1 = \text{``ABABAB''}$ ($N = 6$):} Compute $\pi = [0, 0, 1, 2, 3, 4]$.
    \item \textbf{Candidate period:} $p = N - \pi[N - 1] = 6 - 4 = 2$.
    \item \textbf{Divisibility check:} $p < 6$ and $6 \bmod 2 = 0 \implies$ \textbf{Yes!} $S_1$ is \texttt{"AB"} repeated $6 / 2 = 3$ times.
    \item \textbf{For $S_2 = \text{``ABABA''}$ ($N = 5$):} $\pi = [0, 0, 1, 2, 3]$, so $p = 5 - 3 = 2$. Since $5 \bmod 2 = 1 \neq 0$, $S_2$ is \textbf{not} a whole multiple of a smaller substring (its trailing \texttt{"A"} is incomplete).
\end{enumerate}
\end{example}

\begin{example}[Rabin-Karp Rolling Hash Search by Hand]
Find $P = \text{``bcd''}$ ($L = 3$) inside $T = \text{``abcbcd''}$ using $B = 10$, $M = 97$, and $\text{'a'}=1, \text{'b'}=2, \text{'c'}=3, \text{'d'}=4$.
\begin{enumerate}
    \item \textbf{Precompute high power and target hash:} $B^{L - 1} = 10^2 = 100 \equiv 3 \pmod{97}$. Target $H(P) = (2 \cdot 100 + 3 \cdot 10 + 4) \bmod 97 = 234 \bmod 97 = \mathbf{40}$.
    \item \textbf{Window $0$ (\texttt{"abc"}):} $H_0 = 123 \bmod 97 = 26 \neq 40$.
    \item \textbf{Slide to Window $1$ (\texttt{"bcb"}, out \texttt{'a'}=1, in \texttt{'b'}=2):} Evict: $(26 - 1 \cdot 3) = 23$; shift: $23 \cdot 10 \bmod 97 = 36$; ingest: $36 + 2 = 38 \neq 40$.
    \item \textbf{Slide to Window $2$ (\texttt{"cbc"}, out \texttt{'b'}=2, in \texttt{'c'}=3):} Evict: $(38 - 2 \cdot 3) = 32$; shift: $32 \cdot 10 \bmod 97 = 29$; ingest: $29 + 3 = 32 \neq 40$.
    \item \textbf{Slide to Window $3$ (\texttt{"bcd"}, out \texttt{'c'}=3, in \texttt{'d'}=4):} Evict: $(32 - 3 \cdot 3) = 23$; shift: $23 \cdot 10 \bmod 97 = 36$; ingest: $36 + 4 = \mathbf{40} = H(P)$. Verify \texttt{"bcd"} == \texttt{"bcd"} $\implies$ \textbf{Match at index $3$!}
\end{enumerate}
\end{example}

\begin{example}[Z-Algorithm Search for $P = \text{``aba''}$ in $T = \text{``abacaba''}$]
Form $U = P + \text{`\#'} + T = \text{``aba\#abacaba''}$ (indices $0 \dots 10$, $|P| = 3$).
\begin{enumerate}
    \item $i = 0 \dots 3$: $Z[0] = 0$, $Z[1] = 0$, $Z[2] = 1$ ($U[2]=\text{'a'}$, box $[2, 2]$), $Z[3] = 0$.
    \item $i = 4$: Matches \texttt{"aba"} ($U[4..6] = U[0..2]$) $\implies Z[4] = \mathbf{3}$, box $[4, 6]$. Since $Z[4] = |P|$, \textbf{match at $4 - 4 = 0$}.
    \item $i = 5, 6$: Inside $[4, 6]$, mirror to $1, 2$: $Z[5] = Z[1] = 0$; $Z[6] = \min(6 - 6 + 1, Z[2]) = 1$ ($U[7]=\text{'c'} \neq \text{'b'}$).
    \item $i = 7$: $U[7] = \text{'c'} \implies Z[7] = 0$.
    \item $i = 8$: Matches \texttt{"aba"} ($U[8..10] = U[0..2]$) $\implies Z[8] = \mathbf{3}$, box $[8, 10]$. \textbf{Match at $8 - 4 = 4$}.
    \item $i = 9, 10$: Inside $[8, 10]$, mirror to $1, 2 \implies Z[9] = 0, Z[10] = 1$. Matches found at indices $\mathbf{0}$ and $\mathbf{4}$.
\end{enumerate}
\end{example}

\begin{example}[Shortest Palindrome by Prepending Characters]
What is the fewest characters we can prepend to $S = \text{``aacecaaa''}$ (length $8$) to make it a palindrome?
\begin{enumerate}
    \item \textbf{Build sentinel string:} $U = S + \text{`\#'} + \operatorname{rev}(S) = \text{``aacecaaa\#aaacecaa''}$ (length $17$).
    \item \textbf{Compute $\pi[16]$:} The longest proper prefix of $U$ matching a suffix of $U$ is \texttt{"aacecaa"} (length $\pi[16] = 7$), which is automatically the longest palindromic prefix of $S$!
    \item \textbf{Prepend the unmatched suffix reversed:} Only the last $8 - 7 = 1$ character (\texttt{"a"}) lies outside the palindromic prefix. Prepending its reverse (\texttt{"a"}) produces \texttt{"aaacecaaa"} in $O(N)$ time.
\end{enumerate}
\end{example}

\begin{example}[Manacher's Algorithm on \texttt{"abacaba"}]
Find the longest palindromic substring of $S = \text{``abacaba''}$ ($N = 7$).
\begin{enumerate}
    \item \textbf{Insert sentinels:} $T = \text{``\#a\#b\#a\#c\#a\#b\#a\#''}$ (indices $0 \dots 14$).
    \item \textbf{Expand up to the middle ($i = 0 \dots 7$):}
    $P[0..2] = [0, 1, 0]$;
    at $i = 3$ (\texttt{'b'}), \texttt{"\#a\#b\#a\#"} gives $P[3] = 3$, updating $C = 3, R = 6$;
    $i = 4, 5, 6$ mirror $2, 1, 0$ giving $P[4..6] = [0, 1, 0]$;
    at $i = 7$ (\texttt{'c'}), expanding hits both ends of $T$, giving $P[7] = \mathbf{7}$ and $C = 7, R = 14$.
    \item \textbf{Mirror the entire right half ($i = 8 \dots 14$):} Because $R = 14$ already sits at the end of $T$, every remaining index copies its mirror $P[14 - i]$ with zero extensions: $P[8..14] = [0, 1, 0, 3, 0, 1, 0]$.
    \item \textbf{Decode answer:} Max radius is $P[7] = 7$, start index $(7 - 7)/2 = 0$, length $7 \implies \text{``abacaba''}$.
\end{enumerate}
\end{example}

\section{C++23 Implementations}

Every listing below is standalone C++23, avoids \texttt{using namespace std;}, uses \texttt{std::string\_view} for zero-copy input, guards boundary cases, and compiles cleanly with \texttt{-Wall -Wextra}.

\subsection{Prefix Double Rolling Hash \& Rabin-Karp Search}

\texttt{DoubleHash} precomputes two independent prefix hashes in $O(N)$ using $(31, 10^9 + 7)$ and $(37, 10^9 + 9)$, allowing $O(1)$ substring equality queries over any half-open slice $[l, r)$ and $O(N + M)$ collision-safe Rabin-Karp search.

\begin{lstlisting}[caption={Collision-Safe Double Rolling Hash and O(N + M) Rabin-Karp Search}]
#include <cstdint>
#include <string_view>
#include <utility>
#include <vector>

class DoubleHash {
private:
    static constexpr std::int64_t B1 = 31, M1 = 1'000'000'007LL;
    static constexpr std::int64_t B2 = 37, M2 = 1'000'000'009LL;

    std::vector<std::int64_t> h1_, h2_, p1_, p2_;

public:
    explicit DoubleHash(std::string_view s) {
        std::size_t n = s.size();
        h1_.assign(n + 1, 0);
        h2_.assign(n + 1, 0);
        p1_.assign(n + 1, 1);
        p2_.assign(n + 1, 1);

        for (std::size_t i = 0; i < n; ++i) {
            // Map characters to positive integers (>= 1) so leading 'a's stay distinct
            std::int64_t val = static_cast<unsigned char>(s[i]) + 1;
            h1_[i + 1] = (h1_[i] * B1 + val) % M1;
            h2_[i + 1] = (h2_[i] * B2 + val) % M2;
            p1_[i + 1] = (p1_[i] * B1) % M1;
            p2_[i + 1] = (p2_[i] * B2) % M2;
        }
    }

    // O(1) double hash of half-open slice s[l..r)
    [[nodiscard]] std::pair<std::int64_t, std::int64_t> query(std::size_t l, std::size_t r) const noexcept {
        if (l >= r || r >= h1_.size()) return {0, 0};
        std::size_t len = r - l;
        std::int64_t x1 = (h1_[r] - (h1_[l] * p1_[len]) % M1 + M1) % M1;
        std::int64_t x2 = (h2_[r] - (h2_[l] * p2_[len]) % M2 + M2) % M2;
        return {x1, x2};
    }
};

[[nodiscard]] std::vector<int> rabinKarpSearch(std::string_view text, std::string_view pattern) {
    std::vector<int> matches;
    if (pattern.empty() || pattern.size() > text.size()) return matches;

    DoubleHash th(text);
    DoubleHash ph(pattern);
    auto target = ph.query(0, pattern.size());

    for (std::size_t i = 0; i + pattern.size() <= text.size(); ++i) {
        if (th.query(i, i + pattern.size()) == target) {
            matches.push_back(static_cast<int>(i));
        }
    }
    return matches;
}
\end{lstlisting}

\subsection{KMP Prefix Function ($\pi$-Array) and Search}

\texttt{computePi} builds the longest-border table in $O(M)$ time. Notice we omit \texttt{noexcept} because allocating a \texttt{std::vector} can throw \texttt{std::bad\_alloc}, and we use \texttt{int} lengths throughout to avoid signed/unsigned comparison warnings.

\begin{lstlisting}[caption={KMP Prefix Function and Zero-Backtracking Pattern Search}]
#include <string_view>
#include <vector>

[[nodiscard]] std::vector<int> computePi(std::string_view pattern) {
    int m = static_cast<int>(pattern.size());
    std::vector<int> pi(static_cast<std::size_t>(m), 0);

    for (int i = 1, j = 0; i < m; ++i) {
        while (j > 0 && pattern[i] != pattern[j]) {
            j = pi[j - 1]; // Jump to next longest valid border
        }
        if (pattern[i] == pattern[j]) {
            ++j;
        }
        pi[i] = j;
    }
    return pi;
}

[[nodiscard]] std::vector<int> kmpSearch(std::string_view text, std::string_view pattern) {
    std::vector<int> matches;
    if (pattern.empty() || pattern.size() > text.size()) return matches;

    std::vector<int> pi = computePi(pattern);
    int n = static_cast<int>(text.size());
    int m = static_cast<int>(pattern.size());

    for (int i = 0, j = 0; i < n; ++i) {
        while (j > 0 && text[i] != pattern[j]) {
            j = pi[j - 1];
        }
        if (text[i] == pattern[j]) {
            ++j;
        }
        if (j == m) {
            matches.push_back(i - m + 1);
            j = pi[j - 1]; // Preserve border so overlapping matches are found
        }
    }
    return matches;
}
\end{lstlisting}

\subsection{The Z-Algorithm ($Z$-Array and Search)}

\texttt{computeZ} maintains the rightmost prefix-matching Z-box $[l, r]$ to reuse mirrored prefix lengths in $O(1)$ before extending rightward. \texttt{zSearch} glues \texttt{pattern + '\#' + text} (assuming \texttt{'\#'} is absent from both strings; use any unused byte sentinel if needed).

\begin{lstlisting}[caption={Linear-Time Z-Array and Sentinel-Based Pattern Search}]
#include <algorithm>
#include <string>
#include <string_view>
#include <vector>

[[nodiscard]] std::vector<int> computeZ(std::string_view s) {
    int n = static_cast<int>(s.size());
    std::vector<int> z(static_cast<std::size_t>(n), 0);

    for (int i = 1, l = 0, r = 0; i < n; ++i) {
        if (i <= r) {
            z[i] = std::min(r - i + 1, z[i - l]);
        }
        while (i + z[i] < n && s[z[i]] == s[i + z[i]]) {
            ++z[i];
        }
        if (i + z[i] - 1 > r) {
            l = i;
            r = i + z[i] - 1;
        }
    }
    return z;
}

[[nodiscard]] std::vector<int> zSearch(std::string_view text, std::string_view pattern, char sentinel = '#') {
    std::vector<int> matches;
    if (pattern.empty() || pattern.size() > text.size()) return matches;

    std::string combined;
    combined.reserve(pattern.size() + 1 + text.size());
    combined.append(pattern);
    combined.push_back(sentinel);
    combined.append(text);

    std::vector<int> z = computeZ(combined);
    int m = static_cast<int>(pattern.size());
    int total = static_cast<int>(combined.size());

    for (int i = m + 1; i < total; ++i) {
        if (z[i] == m) {
            matches.push_back(i - m - 1);
        }
    }
    return matches;
}
\end{lstlisting}

\subsection{Cache-Friendly Flat Vector-Pool Trie}

Using integer indices inside a single \texttt{std::vector<TrieNode>} avoids pointer chasing and heap fragmentation. Every lookup checks character bounds (\texttt{'a' <= c <= 'z'}) before indexing to prevent out-of-bounds undefined behavior.

\begin{lstlisting}[caption={Pointerless Vector-Pool Trie with insert, search, and starts\_with}]
#include <array>
#include <string_view>
#include <vector>

class Trie {
private:
    struct Node {
        std::array<int, 26> next{};
        bool is_end = false;

        constexpr Node() noexcept {
            next.fill(-1);
        }
    };

    std::vector<Node> nodes_;

    [[nodiscard]] int walk(std::string_view prefix) const noexcept {
        int curr = 0;
        for (char c : prefix) {
            if (c < 'a' || c > 'z') return -1;
            int idx = c - 'a';
            if (nodes_[curr].next[idx] == -1) return -1;
            curr = nodes_[curr].next[idx];
        }
        return curr;
    }

public:
    Trie() {
        nodes_.emplace_back(); // Node 0 is always the root
    }

    bool insert(std::string_view word) {
        for (char c : word) {
            if (c < 'a' || c > 'z') return false;
        }
        int curr = 0;
        for (char c : word) {
            int idx = c - 'a';
            if (nodes_[curr].next[idx] == -1) {
                nodes_[curr].next[idx] = static_cast<int>(nodes_.size());
                nodes_.emplace_back();
            }
            curr = nodes_[curr].next[idx];
        }
        nodes_[curr].is_end = true;
        return true;
    }

    [[nodiscard]] bool search(std::string_view word) const noexcept {
        int node = walk(word);
        return node != -1 && nodes_[node].is_end;
    }

    [[nodiscard]] bool starts_with(std::string_view prefix) const noexcept {
        return walk(prefix) != -1;
    }
};
\end{lstlisting}

\subsection{Manacher's Algorithm ($O(N)$ Longest Palindromic Substring)}

Transforming \texttt{s} with \texttt{'\#'} separators turns both odd and even palindromes into odd-centered palindromes. The returned \texttt{std::string\_view} slices directly into the caller's input \texttt{s} in $O(1)$ without copying.

\begin{lstlisting}[caption={O(N) Longest Palindromic Substring via Manacher's Algorithm}]
#include <algorithm>
#include <string>
#include <string_view>
#include <vector>

[[nodiscard]] std::string_view longestPalindromeManacher(std::string_view s) {
    if (s.empty()) return {};

    // Build sentinel-interleaved string: "abba" -> "#a#b#b#a#"
    std::string t;
    t.reserve(2 * s.size() + 1);
    t.push_back('#');
    for (char c : s) {
        t.push_back(c);
        t.push_back('#');
    }

    int n = static_cast<int>(t.size());
    std::vector<int> p(static_cast<std::size_t>(n), 0);
    int center = 0, right = 0;
    int best_center = 0, best_len = 0;

    for (int i = 0; i < n; ++i) {
        if (i < right) {
            int mirror = 2 * center - i;
            p[i] = std::min(right - i, p[mirror]);
        }
        while (i - p[i] - 1 >= 0 && i + p[i] + 1 < n &&
               t[i - p[i] - 1] == t[i + p[i] + 1]) {
            ++p[i];
        }
        if (i + p[i] > right) {
            center = i;
            right = i + p[i];
        }
        if (p[i] > best_len) {
            best_len = p[i];
            best_center = i;
        }
    }

    std::size_t start = static_cast<std::size_t>((best_center - best_len) / 2);
    return s.substr(start, static_cast<std::size_t>(best_len));
}
\end{lstlisting}

\begin{calloutbox}{Three-Step String Triage}
\begin{enumerate}
    \item \textbf{Contiguous or Not?} If characters can be skipped (subsequence), jump to Dynamic Programming (Module~06). If slices must be contiguous (substring / prefix / suffix), stay here.

\end{enumerate}
\end{calloutbox}

\subsection*{Core Concepts}
\begin{itemize}
    \item \textbf{Alphabet Size ($\Sigma$):} Number of distinct characters allowed (e.g., $\Sigma = 26$ for lowercase English letters, $\Sigma = 2$ for a bitwise Trie).
    \item \textbf{Birthday Paradox:} The statistical effect where collisions among $N$ random values modulo $M$ become likely around $N \approx \sqrt{M}$, forcing double hashing when $N = 10^5$ and $M \approx 10^9$.
    \item \textbf{Border:} A non-full prefix of a string that is also a suffix of that string.
    \item \textbf{Double Hashing:} Computing two independent polynomial hashes with different bases and prime moduli to reduce collision risk to negligible levels.
    \item \textbf{KMP (Knuth-Morris-Pratt):} Deterministic $O(N + M)$ pattern matching algorithm using the $\pi$ border table so the text pointer never rewinds.
    \item \textbf{Manacher's Algorithm:} Linear-time $O(N)$ algorithm that computes the longest palindrome centered at every character and gap using sentinel interleaving and mirror symmetry.
    \item \textbf{Rolling Hash:} Polynomial hash function whose value can be updated in $O(1)$ when sliding a window or querying a prefix difference.
    \item \textbf{Sentinel Character:} A special character (such as \texttt{'\#'}) absent from the input alphabet used to prevent false matches across concatenated strings or to unify odd/even palindromes.
    \item \textbf{Substring vs.\ Subsequence:} A substring is contiguous; a subsequence may skip characters while keeping relative order.
    \item \textbf{Trie (Prefix Tree):} A rooted tree where each edge is labeled with a character, enabling $O(L)$ dictionary insertion, search, and prefix queries.
    \item \textbf{Z-Box ($[L, R]$):} The rightmost known substring $S[L \dots R]$ equal to prefix $S[0 \dots R - L]$, enabling $O(1)$ mirrored initialization in the Z-Algorithm.
\end{itemize}

\subsection*{Mathematical Symbols}
\begin{itemize}
    \item $S[l \dots r)$: Half-open substring slice containing indices $l, l + 1, \dots, r - 1$ (length $r - l$).
    \item $|S|,\; N,\; M,\; L$: Lengths of string $S$, text $T$, pattern $P$, and query word/window.
    \item $\Sigma$: Alphabet size (branching factor of a Trie).
    \item $B,\; M_1,\; M_2$: Base and prime moduli of a polynomial rolling hash.
    \item $\pi[i]$: KMP prefix function---length of the longest border of $S[0 \dots i]$.
    \item $Z[i]$: Z-function---length of the longest common prefix of $S$ and suffix $S[i \dots N - 1]$.
    \item $P[i]$: Manacher palindrome radius around center $i$ in the sentinel-interleaved string $T$.
    \item $\operatorname{rev}(S)$: The string $S$ written backward.
\end{itemize}

\section*{Practice Sheet: Mixed Pen-and-Paper Drills}

\noindent
Work through these six mixed cold-start drills on scratch paper \emph{without} flipping back to the chapter. No hints are given about which subsection applies.

\begin{tryitbox}{Triage}{Cold-Start String Tool Selection}{ex9}
Pick the optimal technique and target complexity for each disguised problem (assume $N = 10^5$):
\begin{enumerate}
    \item \textbf{Circular Log Check:} Given two length-$N$ strings $A$ and $B$, test whether $B$ is a cyclic rotation of $A$.
    \item \textbf{Command Autocomplete:} Store $50{,}000$ CLI commands and answer $10^5$ queries asking if any command begins with prefix $q$.
    \item \textbf{Longest Duplicate Fragment:} Find the longest substring that appears at least twice inside a single length-$N$ DNA string.
\end{enumerate}
\end{tryitbox}

\begin{tryitbox}{Debug}{Missing Overlapping Matches in KMP}{ex10}
A developer writes this match-handling block inside \texttt{kmpSearch}:
\begin{lstlisting}[numbers=none, xleftmargin=4pt, framexleftmargin=4pt]
if (j == m) {
    matches.push_back(i - m + 1);
    j = 0; // <-- Subtle bug!
}
\end{lstlisting}
Trace $T = \text{``ababa''}$ with $P = \text{``aba''}$ to see which match is missed, and write the 1-line fix.
\end{tryitbox}

\begin{tryitbox}{Twist}{Shortest Palindrome by Appending to the End}{ex11}
Section~4 showed that running KMP on $S + \text{`\#'} + \operatorname{rev}(S)$ finds the fewest characters to \textbf{prepend} to $S$ to form a palindrome.
\begin{enumerate}
    \item How do you modify the sentinel string to find the fewest characters to \textbf{append to the end} of $S$ instead?
    \item Apply your modified string to $S = \text{``abcb''}$ and compute the shortest resulting palindrome.
\end{enumerate}
\end{tryitbox}

\begin{tryitbox}{Trace}{Hand-Slide a Rolling Hash Window}{ex12}
Using $B = 10$, $M = 97$, and $\text{'a'}=1, \text{'b'}=2, \text{'c'}=3, \text{'d'}=4$, slide a window of length $L = 2$ across $T = \text{``abcd''}$. Compute $H(\text{``ab''})$, then update to $H(\text{``bc''})$ and $H(\text{``cd''})$ step by step using the 3-stage evict/shift/ingest formula.
\end{tryitbox}

\begin{tryitbox}{Edge Cases}{All-Identical and Empty-Pattern Killers}{ex13}
Evaluate each algorithm on these boundary inputs:
\begin{enumerate}
    \item For $S = \text{``aaaaa''}$ ($N = 5$), write the full $\pi$-array, the full $Z$-array ($Z[0]=0$), and the maximum Manacher radius.
    \item In \texttt{Trie} containing only \texttt{"cat"}, what do \texttt{search("ca")} and \texttt{starts\_with("ca")} return?
    \item Why must \texttt{kmpSearch} and \texttt{rabinKarpSearch} explicitly guard \texttt{pattern.empty()}?
\end{enumerate}
\end{tryitbox}

\begin{tryitbox}{Derive}{Amortized Proof That KMP Is $O(N)$}{ex14}
In \texttt{computePi}, a \texttt{while (j > 0 \&\& ...)} loop sits inside a \texttt{for (int i = 1; i < n; ++i)} loop.
\begin{enumerate}
    \item By how much can \texttt{j} increase in a single \texttt{for} iteration? What is the maximum total increase of \texttt{j} across the entire loop?
    \item Because \texttt{j = pi[j - 1]} strictly decreases \texttt{j} by at least $1$ and \texttt{j} never drops below $0$, derive a tight upper bound on total \texttt{while} iterations across all $N$ steps.
\end{enumerate}
\end{tryitbox}

\section*{Solutions to Pen-and-Paper Exercises}
\addcontentsline{toc}{section}{Solutions to Pen-and-Paper Exercises}
\markboth{Solutions to Pen-and-Paper Exercises}{}
% ============================================================================

\begin{enumerate}
    \item \label{sol:ex1}\textbf{Exercise 1 (Triage) --- Substring, Subsequence, or Border?}
    \textbf{(1)} \texttt{"aca"} is \textbf{both} a substring ($S[3..5]$) and a subsequence; \texttt{"aaaa"} is a \textbf{subsequence only} (not contiguous).
    \textbf{(2)} Borders of \texttt{"abracadabra"}: \texttt{"a"} (length $1$) and \texttt{"abra"} (length $4$).
    \textbf{(3)} \texttt{std::string::substr} copies $O(N)$ characters per call ($O(N^2)$ total), whereas \texttt{std::string\_view::substr} only adjusts a pointer and length in $O(1)$.
    \trapnote{Listing the entire string \texttt{"abracadabra"} as a border---borders must be \emph{proper} prefixes (strictly shorter than $N$).}

    \item \label{sol:ex2}\textbf{Exercise 2 (Debug) --- Two Rolling Hash Bugs:}
    \textbf{Bug 1:} Mapping \texttt{s[i] - 'a'} gives \texttt{'a' = 0}, so \texttt{"a"} and \texttt{"aa"} both hash to $0$ (immediate false collision!). Fix: use \texttt{s[i] - 'a' + 1}.
    \textbf{Bug 2:} In C++, \texttt{\%} preserves the sign of a negative dividend; when \texttt{H[r] < (H[l] * powB[r - l]) \% M}, the subtraction goes negative. Fix: \texttt{(H[r] - (H[l] * powB[r - l]) \% M + M) \% M}.
    \trapnote{Thinking \texttt{H[r]} is always larger than \texttt{H[l] * powB[len]}---both were reduced modulo $M$, so \texttt{H[r]} can be smaller even though $r > l$.}

    \item \label{sol:ex3}\textbf{Exercise 3 (Trace) --- KMP Table on \texttt{"AABAAAB"}:}
    $\pi = \mathbf{[0, 1, 0, 1, 2, 2, 3]}$. The non-zero fallback occurs at $i = 5$ (\texttt{'A'}): $j = 2$ mismatches ($P[2] = \text{'B'} \neq \text{'A'}$), falls back to $j = \pi[1] = 1$, matches $P[1] = \text{'A'}$, and increments to $2$.
    Period check: \texttt{"ABABAB"} has $p = 6 - 4 = 2$ and $6 \bmod 2 = 0$ (\textbf{yes}); \texttt{"ABABA"} has $p = 5 - 3 = 2$ and $5 \bmod 2 \neq 0$ (\textbf{no}).
    \trapnote{Setting $\pi[5] = 0$ on mismatch at $j = 2$ instead of falling back to $\pi[1] = 1$ (losing the border \texttt{"AA"}).}

    \item \label{sol:ex4}\textbf{Exercise 4 (Trace) --- Z-Box Trace on \texttt{"abacaba"}:}
    $Z = \mathbf{[0, 0, 1, 0, 3, 0, 1]}$. Z-box updates: $[2, 2]$ at $i = 2$, then $[4, 6]$ at $i = 4$. Indices $i = 5$ (mirrors $1 \to Z[1] = 0$) and $i = 6$ (mirrors $2 \to \min(1, Z[2]) = 1$) reuse mirrored values in $O(1)$.
    \trapnote{Forgetting to cap the mirrored value at $R - i + 1$ when $Z[i - L]$ extends past the current Z-box.}

    \item \label{sol:ex5}\textbf{Exercise 5 (Edge Cases) --- Trie Boundary Checks:}
    \textbf{(1)} \texttt{search("car") = false}, \texttt{starts\_with("car") = true}, \texttt{search("cart") = true}, \texttt{starts\_with("") = true} (empty string is a prefix of everything, landing on root $0$).
    \textbf{(2)} $6$ nodes total: root (\texttt{0}), \texttt{'c'}, \texttt{'a'}, \texttt{'t'} (under \texttt{'a'}), \texttt{'r'}, \texttt{'t'} (under \texttt{'r'}).
    \textbf{(3)} \texttt{'A' - 'a' = -32} and \texttt{'-' - 'a' = -52}, causing negative out-of-bounds array indexing (undefined behavior!).
    \trapnote{Counting $1 + 3 + 4 = 8$ nodes instead of $6$---forgetting that \texttt{"cat"} and \texttt{"cart"} share the \texttt{"ca"} path.}

    \item \label{sol:ex6}\textbf{Exercise 6 (Twist) --- Counting Palindromes \& Mirror Check:}
    \textbf{(1)} \texttt{"aaa"} has $6$ palindromic substrings (\texttt{"a"} $\times 3$, \texttt{"aa"} $\times 2$, \texttt{"aaa"} $\times 1$). \texttt{"ababa"} has $9$ ($5$ single chars + \texttt{"aba"} $\times 2$ + \texttt{"bab"} $\times 1$ + \texttt{"ababa"} $\times 1$).
    \textbf{(2)} Mirror of $i = 7$ across $C = 5$ is $i' = 2(5) - 7 = 3$. Lower bound $= \min(R - i, P[3]) = \min(10 - 7, 3) = \mathbf{3}$.
    \trapnote{Forgetting even-length centers (\texttt{i, i+1}) when counting palindromes in \texttt{"aaa"} (yielding $4$ instead of $6$).}

    \item \label{sol:ex7}\textbf{Exercise 7 (Debug) --- Missing Sentinel in \texttt{P + T}:}
    Let $P = \text{``aa''}$ and $T = \text{``aa''}$. Without \texttt{'\#'}, $P + T = \text{``aaaa''}$, so $Z[1] = 3 \ge |P|$ and $Z[2] = 2$. Worse, for $P = \text{``aba''}, T = \text{``ba''}$, $P + T = \text{``ababa''}$ gives $Z[2] = 3$ (a fake match crossing from $P$ into $T$!). Adding \texttt{'\#'} caps every $Z[i]$ ($i > |P|$) at $|P|$ and blocks cross-boundary leaks.
    \trapnote{Assuming checking $i \ge |P|$ alone prevents cross-boundary matches---$Z[i]$ can still read past $P$ into $T$ unless a sentinel stops the match.}

    \item \label{sol:ex8}\textbf{Exercise 8 (Debug) --- Unclamped Z-Box Mirror:}
    Take $S = \text{``aaab''}$ (length $4$): at $i = 1$, $Z[1] = 2$, setting $[L, R] = [1, 2]$. At $i = 2 \le 2$, mirroring gives $z[2] = z[2 - 1] = z[1] = 2$, even though $S[2..3] = \text{``ab''}$ only shares \textbf{1} character with $S[0..1] = \text{``aa''}$! The true value is $Z[2] = 1$, not $2$. Clamping with \texttt{std::min(r - i + 1, z[i - l])} fixes it.
    \trapnote{Thinking omitting \texttt{std::min} only affects runtime---it actually overestimates $Z[i]$ past the verified boundary $R$ and returns wrong answers!}

    \item \label{sol:ex9}\textbf{Exercise 9 (Triage) --- Cold-Start String Tool Selection:}
    \textbf{(1)} Circular Log Check $\to$ \textbf{KMP or Z-Algorithm} searching $B$ in $A + A$, $O(N)$.
    \textbf{(2)} Command Autocomplete $\to$ \textbf{Flat Vector-Pool Trie}, $O(L)$ per query.
    \textbf{(3)} Longest Duplicate Fragment $\to$ \textbf{Binary Search on Length + Double Rolling Hash}, $O(N \log N)$.
    \trapnote{Trying KMP on (3)---KMP only checks prefixes against suffixes, not arbitrary interior repeated substrings.}

    \item \label{sol:ex10}\textbf{Exercise 10 (Debug) --- Missing Overlapping Matches in KMP:}
    On $T = \text{``ababa''}$ and $P = \text{``aba''}$, after matching $T[0..2]$ at $i = 2$, resetting \texttt{j = 0} throws away the trailing \texttt{'a'} ($T[2]$). At $i = 3$ (\texttt{'b'}), \texttt{'b' != 'a'}, so the overlapping match at index $2$ ($T[2..4]$) is completely missed!
    \textbf{1-line fix:} Replace \texttt{j = 0;} with \texttt{j = pi[j - 1];}.
    \trapnote{Assuming a full match means the prefix memory is empty---a matched pattern like \texttt{"aba"} can share a border with the next overlapping occurrence.}

    \item \label{sol:ex11}\textbf{Exercise 11 (Twist) --- Shortest Palindrome by Appending:}
    \textbf{(1)} Flip the order to $\operatorname{rev}(S) + \text{`\#'} + S$: now $\pi[\text{end}]$ equals the length of the longest \textbf{palindromic suffix} of $S$.
    \textbf{(2)} For $S = \text{``abcb''}$, $U = \text{``bcba\#abcb''}$ has $\pi[8] = 3$ (\texttt{"bcb"}). Reverse the unmatched prefix \texttt{"a"} and append it $\implies \text{``abcba''}$.
    \trapnote{Using $S + \text{`\#'} + \operatorname{rev}(S)$ and trying to append instead of prepend---that gives the longest palindromic \emph{prefix}, not suffix.}

    \item \label{sol:ex12}\textbf{Exercise 12 (Trace) --- Rolling Hash Slide on \texttt{"abcd"} ($L = 2$):}
    $B^{L - 1} = 10^1 = 10$.
    $H(\text{``ab''}) = (1 \cdot 10 + 2) = \mathbf{12}$.
    Slide to \texttt{"bc"} (out \texttt{'a'}=1, in \texttt{'c'}=3): $(12 - 1 \cdot 10) = 2 \to 2 \cdot 10 = 20 \to 20 + 3 = \mathbf{23}$.
    Slide to \texttt{"cd"} (out \texttt{'b'}=2, in \texttt{'d'}=4): $(23 - 2 \cdot 10) = 3 \to 3 \cdot 10 = 30 \to 30 + 4 = \mathbf{34}$.
    \trapnote{Multiplying the evicted character by $B^L = 100$ instead of $B^{L - 1} = 10$.}

    \item \label{sol:ex13}\textbf{Exercise 13 (Edge Cases) --- Killer Boundary Inputs:}
    \textbf{(1)} On \texttt{"aaaaa"}: $\pi = [0, 1, 2, 3, 4]$;\; $Z = [0, 4, 3, 2, 1]$;\; Manacher max radius $= 5$ (entire string).
    \textbf{(2)} \texttt{search("ca") = false}, \texttt{starts\_with("ca") = true}.
    \textbf{(3)} If \texttt{pattern.empty()}, \texttt{j == m} triggers immediately and accesses \texttt{pi[j - 1] = pi[-1]} (out-of-bounds crash!) or produces $N + 1$ empty matches.
    \trapnote{Writing $\pi(\text{"aaaaa"}) = [1, 2, 3, 4, 5]$---$\pi[0]$ is always $0$ because a border must be strictly shorter than the prefix.}

    \item \label{sol:ex14}\textbf{Exercise 14 (Derive) --- Amortized KMP Bound:}
    \textbf{(1)} Each \texttt{for} iteration increments \texttt{j} by at most $+1$ (at most $N - 1$ total increments across $i = 1 \dots N - 1$).
    \textbf{(2)} Each \texttt{while} step strictly lowers \texttt{j} by $\ge 1$, and \texttt{j} starts at $0$ and never becomes negative. Therefore the \texttt{while} loop executes at most $N - 1$ times \emph{total} across the entire run, yielding $\le 2N - 2 = O(N)$ character comparisons.
    \trapnote{Multiplying worst single-step fallbacks ($O(N)$) by $N$ outer iterations to mistakenly conclude $O(N^2)$.}
\end{enumerate}
