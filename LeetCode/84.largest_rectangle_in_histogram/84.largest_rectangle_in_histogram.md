# 84. Largest Rectangle in Histogram

https://leetcode.com/problems/largest-rectangle-in-histogram/description/

Given an array of integers `heights` representing the histogram's bar height where the width of each bar is `1`, return the area of the largest rectangle in the histogram.

## Example 1:

```text
 6 |             +---+
 5 |         +---+   |
 4 |         |###|###|
 3 |         |###|###|   +---+
 2 | +---+   |###|###+---+   |
 1 | |   +---+###|###|   |   |
   +-+---+---+---+---+---+---+
idx:   0   1   2   3   4   5
val:   2   1   5   6   2   3
```

- **Input**: `heights = [2,1,5,6,2,3]`
- **Output**: `10`
- **Explanation**: The above is a histogram where the width of each bar is 1.
  The largest rectangle is shown in the shaded (`#`) area between indices 2 and 3, which has an area of `5 * 2 = 10` units.

## Example 2:

```text
 4 |     +---+
 3 |     |   |
 2 | +---+   |
 1 | |###|###|
   +-+---+---+
idx:   0   1
val:   2   4
```

- **Input**: `heights = [2,4]`
- **Output**: `4`
- **Explanation**: The largest rectangle has an area of 4 (either height 4 and width 1 at index 1, or height 2 and width 2 across indices 0 and 1).

## Constraints:

- `1 <= heights.length <= 10^5`
- `0 <= heights[i] <= 10^4`
